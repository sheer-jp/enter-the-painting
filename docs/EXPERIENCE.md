# 体験仕様（場面ごと）

これが「作るもの」の定義。`docs/PLAN.md` の思いを、見えるもの・聞こえるもの・数値に落とす。
迷ったらここに戻る。数値は初期値で、実機で詰めたら書き換える（変更はログに残す）。

## 一言で

**手元の絵に近づくと、絵が流体になって自分の全部を包む。奥から文字がふんわり浮いてきて、母語でメッセージを読める。**

## 0. 前提

- 視点の高さは実際の目の高さ（VR）、1.6m 固定（PC / スマホ）
- 絵は最初、目の前 3m の壁に「実物と同じ寸法」で掛かっている。小さい（手のひら大）ことが入口の大事な点。ここから大きくなる
- 言語は端末の言語で自動的に決まる。選ばせない（切り替えはできる）。文字は必ず母語で出す
- 音は「入る」操作の後にしか鳴らさない（ブラウザの制約）

## 1. 場面の流れ

| # | 場面 | 長さ | きっかけ |
| --- | --- | --- | --- |
| G | ギャラリー | 任意 | オンラインで来た人が作品を選ぶ |
| S0 | 入口（作品ページ） | 任意 | QR / URL / ギャラリーから作品ページを開く |
| S1 | 接近 | 2〜20 秒 | 絵をタップするとギュンと近づく（歩いてもよい） |
| S2 | 溶ける | 約 2 秒 | 絵まで 1.0m を切る |
| S3 | 包まれる | 約 4 秒 | S2 完了 |
| S4 | 漂う | 任意（声の長さ 1〜3 分が目安） | S3 完了。文字が浮き始める |
| S5 | 戻る | 約 3 秒 | 「戻る」操作、または文字がすべて流れ終わって 60 秒 |

### G ギャラリー（オンラインの入口）

- **見える**：5 作品の写真が実物の寸法比で並ぶ（大きい絵は大きく、小さい絵は小さく）。タイトルと寸法。言語の表示
- **やること**：1 枚を選ぶと、その作品ページ（S0）へ
- **2 つの入口**：会場では QR を読んで作品ページに直接着く。オンラインではギャラリーから選ぶ。着く先は同じ作品ページ
- **受け入れ条件**：5 作品が並び、どれを選んでも 2 秒以内に S0 が出る

### S0 入口（作品ページ）

- 作品ごとに固定 URL `/w/<id>/` のページがある。QR はこの URL を指す。共有したときに絵とタイトルが出る（OGP）

- **見える**：画面中央に絵の写真（実物比率）。下にタイトル、寸法、作家名。「入る」ボタン。言語の表示（例：日本語 ▾）。VR 対応端末では「VR で入る」も出す
- **やること**：「入る」を押す。ここで音の許可・ジャイロ許可・XR セッション開始をまとめて行う
- **受け入れ条件**：QR 読み取りから「入る」が押せるまで、4G で 5 秒以内（画像は 2048px の JPEG 1 枚と space.json のみ先読み）

### S1 接近

- **見える**：薄暗い空間。目の前 3m の壁に小さな絵が掛かっている。絵は実物の寸法（例：18cm × 14cm）。絵の表面には、すでにごくかすかな流れ（筆致に沿う、振幅 1〜2px 相当）がある。近づくほど流れは強くなる
- **聞こえる**：環境音が小さく（-24dB）。絵に近づくほど絵の方向から音が大きくなる（位置付き音源）
- **入力**
  - **主**：絵をタップ（スマホ）/ クリック（PC）/ 絵に向けてトリガー（VR）すると、絵に向かって**ギュンと近づく**。1.2 秒で 1.0m（溶ける距離）まで。加速してから減速（ease-in-out）。到着と同時に S2 へ
  - 副：歩いて近づいてもよい。VR は実際に歩く / スティック 0.8m/s、PC は W / ↑ 1.2m/s、スマホは画面長押し 1.0m/s
  - 共通：15 秒操作がなければ自動でゆっくり接近（0.3m/s）。初めての人が止まらないため（入れるかは実機で決める）
  - 絵は近づく前でも「押せる」とわかるように、視線が絵に乗ったとき（画面中央 ±10°）に表面の流れがわずかに強まる
- **受け入れ条件**：絵をタップしてから 2 秒以内に S2 が始まる。タップしなくても 30 秒以内に S2 に到達する

### S2 溶ける（流体化）

- **きっかけ**：視点から絵までの距離が 1.0m を切る
- **見える**：絵の表面が、縁から内側へ向かって流体になる。絵の具が筆致の方向に流れ出し、色が混ざらずに渦を巻く（混ざりすぎると濁るので、拡散は最小）。約 2 秒で絵全体が動く。絵の平面は保ったまま
- **聞こえる**：環境音に低い持続音（ドローン）が重なり始める
- **数値**：流体シミュレーションの解像度 256×256（速度場）、1024×1024（色）。渦の持続 0.98、拡散 0。絵の筆致の流れ場（`flow.png`）を初期速度にする
- **受け入れ条件**：流れ出したあとも、絵の主要な色と構図が「あの絵だ」と見分けられる（作家が判定）。2 秒で全面が動く

### S3 包まれる

- **きっかけ**：S2 完了
- **見える**：流体になった絵が、平面から視点を中心とした球面（半径 2.5m）へ約 4 秒でふくらむ。絵の縁が視界の外へ広がり、最後は上下左右と背後まで色が満たす。視界の中に「絵でない場所」が無くなる。カメラは動かさない（酔い対策）。絵が自分に向かって来る
- **聞こえる**：環境音が全方向から鳴る。ドローンが最も大きくなり（-12dB）、その後 S4 で落ち着く
- **入力**：S3 の間は移動を受け付けない。見回しは常に有効
- **数値**：半径 2.5m、ふくらむ時間 4 秒（イージング ease-in-out）。球面の裏側（元の絵が無かった方向）は、絵の主要色のグラデーションに流体が流れ込んで埋まる
- **受け入れ条件**：VR で 4 秒後に、頭をどの方向に向けても絵の色がある。「包まれた」と作家が感じる。S2 と S3 を通して Quest で 72fps を保つ（落ちたら色の解像度を 512 に下げる）

### S4 漂う（文字が浮いてくる）

- **見える**
  - 流体は球面上でゆっくり流れ続ける。視線の向きに流れがわずかに引き寄せられる（視線方向に毎秒 0.2 の力）
  - **文字**：視線の先の奥（球面の向こう、見かけの距離 8m）から、作家のメッセージが 1 文ずつ浮き上がってくる。最初は小さく・透明で・にじんでいる。6 秒かけて読める距離（2m）まで前に来て、くっきりする。そこで文の長さに応じて止まる（1 文字あたり 0.25 秒、最短 4 秒）。そのあと 3 秒でほどけて流体に溶ける。次の文が奥から来る
  - 文字は 1 文ずつ、同時には 1 つだけ。文字の色は絵の主要色のうち最も明るい色、縁取りなし、半透明の帯も置かない（流体の上に直接浮く）
  - 文字は**閲覧者の母語**で出る。作家の原文（日本語）の雰囲気を保った訳文
  - 文字は常に視線の方向から来る。横を向いていれば横の奥から来る（文字のためにユーザーを向き直らせない）
- **聞こえる**：作家の声（日本語のみ）が流れる。声の文と浮いてくる文字は同じ文を指す。母語が日本語でない人には、声は日本語のまま、文字が母語で出る（字幕の役割）。声は訳さない。作家の声そのものが体験の一部。声の各文の開始時刻（`captions[].at`）で文字の出現を揃える
- **入力**：移動はできない。見回しのみ。「戻る」操作（VR：どちらかのコントローラの B / Y 長押し、PC：Esc、スマホ：画面右上のボタン）
- **数値**：出現距離 8m → 読める距離 2m、浮上 6 秒、滞在 = max(4 秒, 0.25 秒 × 文字数)、溶ける 3 秒。文字サイズは 2m 距離で高さ 12cm（視角 約 3.4°）。1 文は 40 文字以内（日本語）、2 行まで
- **受け入れ条件**：VR・PC・スマホのすべてで文字が読める（第三者 3 人が読み上げられる）。日本語と英語で表示できる。文字と声の文が一致する

### S5 戻る

- **見える**：流体が 3 秒で球面から元の平面へ縮み、壁の小さな絵に戻る。絵の静止画がもう一度はっきり見える（「あの小さい絵の中に、今のがあった」と思えるように）
- **聞こえる**：声と環境音がフェードアウト
- **そのあと**：S0 に戻る。「もう一度入る」と「他の作品」。

## 2. 3 環境の違い（まとめ）

| | VR（Quest ブラウザ） | PC | スマホ |
| --- | --- | --- | --- |
| 見回し | 頭 | マウス | ジャイロ（拒否時はドラッグ） |
| 接近 | 絵にトリガー（歩く / スティックでも） | 絵をクリック（W / ↑ でも） | 絵をタップ（長押しでも） |
| 自動接近 | 15 秒無操作で開始 | 同左 | 同左 |
| 包まれる | 全方向（本物） | 画面いっぱい、見回せば全方向 | 画面いっぱい、端末を回せば全方向 |
| 文字 | 空間内に浮く | 同じ | 同じ（画面幅に合わせて縮む。最小でも 1 行 14 文字） |
| 戻る | B / Y 長押し | Esc | 右上ボタン |

同じ Scene・同じ流体・同じ文字。違うのは入力だけ。

## 3. 言語

- **方針**：母語で読めないと心に入ってこない。選ばせず、端末の言語で自動的に母語にする。切り替えは S0 の表示から可能。`?lang=` で固定もできる（QR ごとに言語を変えたいときに使う）
- **対応言語（10）**：日本語 `ja`、英語 `en`、中国語（簡体）`zh-Hans`、中国語（繁体）`zh-Hant`、韓国語 `ko`、フランス語 `fr`、ドイツ語 `de`、スペイン語 `es`、イタリア語 `it`、ポルトガル語 `pt`
  - 美術館・ギャラリー文化の厚い国と、来場者の多い言語を優先した。アラビア語・ヘブライ語は右から左に書くため、文字描画の対応が必要なので今回は外す
- **訳の作り方**：作家が日本語で書く → 英語は作家が目を通す → 残り 8 言語は Claude API で日本語原文と英語の両方を渡して訳す。訳は `space.json` に埋め込み、実行時に翻訳 API は呼ばない。UI 文言（「入る」「戻る」など）も同じ 10 言語
- **フォント**：Noto Sans（ラテン文字）、Noto Sans JP、Noto Sans SC、Noto Sans TC、Noto Sans KR。言語に応じて必要なフォントだけ読む（各 1〜3MB、サブセット化で減らす）
- **声**：日本語のみ（作家の声）。他の言語は声は日本語のまま、文字が母語。声は訳さない
- **受け入れ条件**：端末が英語設定の iPhone で開くと、何も選ばずに英語で「入る」と文字が出る。10 言語それぞれで S4 の文字が崩れず表示される（スクリーンショットで確認）

## 4. 決めていないこと（実機で決める）

- 流体の「混ざり」の加減。濁らず、でも流れている、の境目
- S3 の半径（2.5m）。近すぎると圧迫、遠すぎると包まれない
- 文字の浮上時間（6 秒）。待たせすぎないか
- 自動接近を入れるか。タップで近づけるので要らないかもしれない。実機で止まる人がいるかを見て決める
- ギュンと近づく速さ（1.2 秒）。速すぎると酔う、遅いと「ギュン」でなくなる
