# 提出動画の構成（3 分以内、11-06 深夜、Fable）

ハッカソン（Claude）への提出動画。作家の指示：「3 分以内。どういうものか、機能が全部わかる。どの課題をどう解決して、何が起きるか。洗練されていて、おしゃれで、テンポが良くて、どんどん切り替わる。日本語で具体的に解説。音声は後から入れるので、まず文章と字幕」。

## 0. 一言（動画の芯）

**「私がその場にいなくても、絵の魅力が伝わる。」**

作家の原点（11-06 の語り）：在廊していれば絵の魅力を語れる。でも、いないとき——オンラインで絵を買うとき、美術館で絵の前に立つとき——同じように伝えるのは難しい。だから、会話で「今のあなたに合う絵」を見つけ、絵の中に入って作家の思いを聞く場所を作った。ゴールは VR で絵の色の世界に包まれること。

## 1. 全体の設計

- **長さ**：2 分 50 秒 ± 10 秒（3 分以内に余裕を残す。審査は最初の 30 秒で見るかどうかを決めるので、冒頭に体験の絵を置く）
- **テンポ**：カットは 2〜5 秒。1 章 = 15〜30 秒。文字は 1 画面 1 文（最長 2 行）。切り替えはハードカット（拍で切る）。フェードは章の変わり目だけ
- **画面**：16:9、1920×1080。スマホの画面は 9:16 のまま中央に置き、左右は紙白（#f6f4ef）の余白に字幕と小さな見出し。PC・VR の画面は全画面
- **トーン**：サイトと同じ。紙白、明朝（Shippori Mincho）、細いゴシック、黒の細い線。派手な効果音・エフェクトは使わない。「切り替わる速さ」でテンポを作る
- **字幕**：画面下 1/5 に明朝 44px、黒、白の薄い縁取り。英語は入れない（提出は日本語）。章の見出しは左上に小さく（例「01 悩み」）
- **音声**：あとから作家の声を入れる。字幕の文がそのままナレーション原稿。音楽は作家が選ぶ（無音で成立させる）
- **撮る素材**：(a) 受付 → C2 → 絵の中（スマホの画面録画、Playwright で 390×844）、(b) 物語モードの長回し（PC 1920×1080、頂・花・New Chapter）、(c) ギャラリーと作品ページ（PC とスマホ）、(d) **Quest の録画**（作家が撮る。S1 → S2 → S3 → S4。1 人称）、(e) 会場の小さな絵の実写（作家、スマホで 10 秒。手のひらと比べる）、(f) ターミナルの早回し（`npm run generate`）

## 3. 作り方（Opus への発注。V1 は無音・字幕焼き込み）

1. **素材の録画**（Playwright、`recordVideo`）
   - スマホ：390×844、`deviceScaleFactor 3`、`https://enter-the-painting.pages.dev/` から 03 と 07 の流れ。`window.__ETP_FAST` は使わない（本来の間で）。受付の AI は本番 API（2〜3 往復）
   - PC：1920×1080、物語モードを `/w/itadaki/?via=concierge`（「絵の世界をのぞく」）で 04。New Chapter・花・本能は 05 用に各 20 秒（`GPU=1` でなく実ブラウザの GPU が要るので、Playwright は headless: false の Chromium で。SwiftShader では流体が遅い）
   - ターミナル：`asciinema` か、Playwright でターミナル風の HTML を再生して録る（簡単な方）
   - Quest：**作家が撮る**（`docs/VIDEO.md` 2 節 06）。無いあいだは `?space=flat` の 6 方向の画を 1 秒ずつ並べた仮の映像
   - 実写（会場の絵、作家）：作家が撮る。無いあいだは作品写真に「実写はあとで」の仮札
2. **編集**（ffmpeg）：章ごとに mp4 を作り、`concat`。字幕は `drawtext`（Shippori Mincho、44px、黒、白の縁 2px、下 1/5）。章の見出しは左上 22px。スマホの画面は 9:16 を 1920×1080 の中央に、左右は紙白。ハードカット。章の変わり目だけ 0.3 秒のフェード
3. **出力**：`_meta/development/enter-the-painting/video/v1/enter-the-painting_v1.mp4`（H.264、1080p、30fps）と、章ごとの mp4、字幕の srt（あとで声を入れるとき用）。各章の代表フレーム png
4. **検査**：3 分以内、字幕が全部読める（1 文 3 秒以上）、画面の切り替えが 2〜5 秒、白飛びなし

## 4. 作家が用意するもの

- Quest の 1 人称録画（S1 → S4、60 秒。頂と Harmoney）
- 会場の小さな絵の実写（手のひらと比べる、10 秒）
- 在廊中の写真か、描いている手元（5 秒）
- ナレーション（2 節の字幕をそのまま読む。あとで差し替え）
- 音楽（任意）
