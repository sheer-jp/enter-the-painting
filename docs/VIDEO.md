# 提出動画の構成（3 分以内、11-06 深夜、Fable）

ハッカソン（Claude）への提出動画。作家の指示：「3 分以内。どういうものか、機能が全部わかる。どの課題をどう解決して、何が起きるか。洗練されていて、おしゃれで、テンポが良くて、どんどん切り替わる。日本語で具体的に解説。音声は後から入れるので、まず文章と字幕」。

## 0. 一言（動画の芯）

**「私がその場にいなくても、絵の魅力が伝わる。」**

作家の原点（11-06 の語り）：在廊していれば絵の魅力を語れる。でも、いないとき——オンラインで絵を買うとき、美術館で絵の前に立つとき——同じように伝えるのは難しい。だから、会話で「今のあなたに合う絵」を見つけ、絵の中に入って作家の思いを聞く場所を作った。ゴールは VR で絵の色の世界に包まれること。

## 1. 全体の設計

- **長さ**：2 分 50 秒 ± 10 秒（3 分以内に余裕を残す。審査は最初の 30 秒で見るかどうかを決めるので、冒頭に体験の絵を置く）
- **テンポ**：カットは 2〜5 秒。1 章 = 15〜30 秒。文字は 1 画面 1 文（最長 2 行）。切り替えはハードカット（拍で切る）。フェードは章の変わり目だけ
- **画面**：16:9、1920×1080。スマホの画面は 9:16 のまま中央に置き、左右は紙白（#f6f4ef）の余白に字幕と小さな見出し。PC・VR の画面は全画面
- **トーン**：サイトと同じ。紙白、明朝（Shippori Mincho）、細いゴシック、黒の細い線。派手な効果音・エフェクトは使わない。「切り替わる速さ」でテンポを作る
- **字幕**：画面下 1/5 に明朝 44px、黒、白の薄い縁取り。英語は入れない（提出は日本語）。章の見出しは左上に小さく（例「01 悩み」）
- **音声**：あとから作家の声を入れる。字幕の文がそのままナレーション原稿。音楽は作家が選ぶ（無音で成立させる）
- **撮る素材**：(a) 受付 → C2 → 絵の中（スマホの画面録画、Playwright で 390×844）、(b) 物語モードの長回し（PC 1920×1080、頂・花・New Chapter）、(c) ギャラリーと作品ページ（PC とスマホ）、(d) **Quest の録画**（作家が撮る。S1 → S2 → S3 → S4。1 人称）、(e) 会場の小さな絵の実写（作家、スマホで 10 秒。手のひらと比べる）、(f) ターミナルの早回し（`npm run generate`）

## 3. 作り方（Opus への発注。V1 は無音・字幕焼き込み）

1. **素材の録画**（Playwright、`recordVideo`）
   - スマホ：390×844、`deviceScaleFactor 3`、`https://enter-the-painting.pages.dev/` から 03 と 07 の流れ。`window.__ETP_FAST` は使わない（本来の間で）。受付の AI は本番 API（2〜3 往復）
   - PC：1920×1080、物語モードを `/w/itadaki/?via=concierge`（「絵の世界をのぞく」）で 04。New Chapter・花・本能は 05 用に各 20 秒（`GPU=1` でなく実ブラウザの GPU が要るので、Playwright は headless: false の Chromium で。SwiftShader では流体が遅い）
   - ターミナル：`asciinema` か、Playwright でターミナル風の HTML を再生して録る（簡単な方）
   - Quest：**作家が撮る**（`docs/VIDEO.md` 2 節 06）。無いあいだは `?space=flat` の 6 方向の画を 1 秒ずつ並べた仮の映像
   - 実写（会場の絵、作家）：作家が撮る。無いあいだは作品写真に「実写はあとで」の仮札
2. **編集**（ffmpeg）：章ごとに mp4 を作り、`concat`。字幕は `drawtext`（Shippori Mincho、44px、黒、白の縁 2px、下 1/5）。章の見出しは左上 22px。スマホの画面は 9:16 を 1920×1080 の中央に、左右は紙白。ハードカット。章の変わり目だけ 0.3 秒のフェード
3. **出力**：`_meta/development/enter-the-painting/video/v1/enter-the-painting_v1.mp4`（H.264、1080p、30fps）と、章ごとの mp4、字幕の srt（あとで声を入れるとき用）。各章の代表フレーム png
4. **検査**：3 分以内、字幕が全部読める（1 文 3 秒以上）、画面の切り替えが 2〜5 秒、白飛びなし

## 4. 作家が用意するもの

- Quest の 1 人称録画（S1 → S4、60 秒。頂と Harmoney）
- 会場の小さな絵の実写（手のひらと比べる、10 秒）
- 在廊中の写真か、描いている手元（5 秒）
- ナレーション（2 節の字幕をそのまま読む。あとで差し替え）
- 音楽（任意）

## 5. V2 の直し方（11-07、作家「作り込みが甘い。途中で違う絵にすり替わる。つかみに本物の絵が無い」）

- **絵は 1 点で通す**：03 受付で AI がすすめた絵と、04 絵の中へ・07 戻る・10 結びの絵を**同じ作品**にする。狙いは **頂**（渦 → 静かに戻る、が一番映える）。受付の自由文は「大きな挑戦を前にした朝。白い壁の仕事場に、パワーの出る絵を」のように頂に寄せ、頂が出るまで撮り直す（最大 3 回）。どうしても別の絵なら、その絵で 04〜10 を通す（すり替えない）
- **つかみは本物の絵**：生成画像の無地のキャンバスはやめる。`works/<id>/generated/room_*.jpg`（AI 生成の部屋に**実物の写真**を射影で合成したもの。絵は生成モデルに入れていない）を使う。00 は「玄関の壁に掛かった頂」→ 寄って「53 × 45.5 cm」の字幕。小ささを見せるカットは New Chapter の `room_studio-desk.jpg`（18 × 14 cm、机の上）
- **01 の作家の手元**：生成でよい（顔なし）。04 の「絵をタップすると」は、実際に C2 の絵をタップする操作で撮る
- **06 VR は本物の場面**：`?space=flat` で空間モードを実 GPU の Chromium で動かし、カメラをゆっくり左右に振りながら 20 秒録る（必要なら `?spin=1` で自動の首振りを足す。`src/experience/main.ts` の最小の差分）。粒・床の反射・奥の光が映る。生成のイメージ画像は使わない。札は「PC での再現（Quest の録画はあとで差し替え）」
- **最新の画面で撮り直す**：見出し「SHEER Gallery」、あいさつ 3 文、白い背景、ボタンだけの最初の画面
- **テンポ**：08・09 も 1 画面 5 秒以内に割る（ターミナルは 3 カット、Claude は docs 一覧 → system → voice.json の 3 カット）
- **検査**：絵が途中で変わっていないこと（03 のカード、04 の T0、07 の作品ページ、10 の戻りで同じ題名）、字幕は原稿どおり、3 分以内

## 6. V3 の作り込み（11-07、作家「全部の編集が終わってから、動画をもっと作り直して細かく。BGM は自分の既存曲から 1 つ」）

**BGM は「花を手向ける」**（作家の既存曲、インスト、4:00、約 98 BPM、-15 LUFS。`_meta/development/enter-the-painting/video/bgm/hana-wo-tamukeru.wav`）。作家の決定（11-07）。

- **音**：BGM を 2:55 に合わせて 0:00 から。頭 1.0 秒フェードイン、終わり 3.0 秒フェードアウト。全体 -16 LUFS（ナレーション無しの版）。あとでナレーションを足す前提で、-20 LUFS の「声用」版も書き出す（`_bgm-for-voice.wav`）。拍（0.612 秒）に**カットを合わせる**：各カットの長さは 2 拍の倍数（1.22 / 2.45 / 3.67 / 4.9 秒）。章の変わり目はフレーズ頭（8 拍 = 4.9 秒の倍数）に寄せる。`tools/timeline.json` に拍の格子を入れ、`check.py` でカットが拍から ±2 フレーム以内か検査
- **撮り直し（本番の最新。配置の ID を README に）**：
  - 03 受付：カフェの背景（木なし、Harmoney 1 点）、ボタンだけの最初の画面、「寂しい夜に寄り添ってほしい」。スマホ 2 倍解像度
  - 04 絵の中へ：太く大きくなった文字（白文字に墨のにじみ、頂）。1 文ずつ切り替わるテンポが伝わるよう、**2 倍速にしない**（流れは最短 40 秒なので、渦 → 戻りは 3 倍速の区間を別に作る）
  - 07 戻る・部屋：作品ページ（墨の主ボタン）→ 部屋で見る → **拡大表示で絵をドラッグして動かす**（新機能。「好きな場所へ」の案内が見える）→ 「他の作品」→「ギャラリー全体を見る」→ ギャラリー（PC は一列に収まる壁）
  - **07b 小さな絵**（新しい章、8 秒）：New Chapter の作品ページ → 机のイーゼル・靴箱の上・棚に立てかけ（置く部屋）。字幕「小さな絵は、机や靴箱の上に。」「寸法は、机やノート PC と比べて。」
  - 05 絵ごとの世界：V1 の録画をやめ、最新で撮り直す（文字色・太さが変わったため）
  - 06 VR：V2 のまま（S4 の 3 カット）。頭の第三者視点は生成のまま（札）
- **磨き**：
  - 文字（字幕・章の見出し・題名）は Shippori Mincho **600**、サイトと同じ比率。字幕は下 1/5、白地の帯は使わず白のにじみ（サイトの絵の中と同じ）。写真の上では帯 `rgba(255,255,255,.85)`
  - 写真は必ず動かす（寄る・引く 3〜5%、Ken Burns）。3 秒以上の静止画を置かない
  - 色：全ショットを tv レンジに統一（V2 で直した）。サイトの画面録画は白が #ffffff、写真は補正しない
  - 切り替えはハードカット。章の変わり目だけ 0.3 秒の白フェード（黒は使わない）
  - 冒頭 10 秒：音の立ち上がりと「絵の中に、入る。」の出をフレーズ頭に
  - 最後：URL と QR → 「絵の中に、入る。」→ BGM のフェードアウトに合わせて白へ
- **検査**：3 分以内、絵の一貫性（頂）、字幕は原稿どおり（07b の 2 文を 2 節の表に足す）、カットが拍に乗っている、ラウドネス -16 ± 1 LUFS、ピーク -1 dBTP
- **出力**：`video/v3/enter-the-painting_v3.mp4`（1080p、AAC 192k）、`_720p.mp4`（30MB 以下）、`subtitles.srt`、`README.md`（V2 からの差分、使った配置 ID、拍の合わせ方）
