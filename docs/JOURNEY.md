# ユーザージャーニー V2

体験の全体を、人ごとに時間の流れで想像する。各場面に「見る・する・感じる」と、離脱しそうな点を書く。
場面の記号（G、S0〜S5、T0〜T5）は `docs/EXPERIENCE.md`、要件 ID は `docs/REQUIREMENTS.md`。

---

## J1. 個展の来場者（B）が、小さな絵の前で立ち止まる

**ある土曜の午後。ギャラリーに来た人。作家の絵は初めて見る。**

| 時刻 | 場面 | 見る・する | 感じる | 離脱しそうな点 |
| --- | --- | --- | --- | --- |
| 0:00 | 会場 | 大きな作品の前で立ち止まり、しばらく見る。壁の端に手のひら大の小品が 5 点 | 大きい絵はすごい。小さい絵は「かわいい」 | ここで小品を素通りする（P1） |
| 0:30 | 会場 | 小品のキャプションに QR と「この絵の中に入れます」の一言。スマホを向ける | 何だろう | QR の意図がわからない。一言が要る（F-23） |
| 0:40 | S0 | 作品ページが開く。絵がすぐ出る。タイトル、寸法、「入る」 | 速い。さっき見た絵だ | 読み込みに 5 秒以上かかると閉じる（N-01、N-02） |
| 0:45 | S0 | 「入る」を押す。スマホは消音のまま | 会場で音を出していいのか迷う。消音なので声は聞こえない | 会場ではほぼ消音。文字だけで通じること（F-05）。声が鳴らない理由を「壊れた」と思わせない |
| 0:50 | T0〜T2 | 絵が画面いっぱいにギュンと拡大し、縁からシュワシュワと溶けて流れ出す | おっ、と声が出る。さっきの小さい絵が動いている | 流れ出したあと「あの絵」とわからなくなると冷める（F-01） |
| 1:00 | T3 | 流体の奥から文字が浮く。「海辺の町で描いた。」作家の声は小さく聞こえる | 絵の向こうに場所があるとわかる | 文字が読みにくい、速すぎる（F-05 の数値） |
| 2:30 | T4〜T5 | 流体がゆっくり絵に戻る。QR 経由なので「実物の前でもう一度」と「保存・共有」が先頭に。「部屋で見る」「作家に連絡」 | 「あの小さい絵の中に、今のがあった」。もう一度、実物を見に行く | ここで終わると「面白かった」で終わる。実物に戻る導線（F-26） |
| 3:30 | 会場 | （U-14 で「会場に Quest を置く」なら）小品の横の Quest をスタッフに渡され、2 分だけ入る | 全身で包まれる。スマホとは別物 | 順番待ち、衛生、スタッフの手間。Quest 無しなら物語モードだけで成立させる |
| 3:00 | 会場 | 実物の小品の前に戻る。さっきより長く見る。作家が在廊していれば話しかける | この絵なら家に置ける、と初めて思う | |
| 後日 | S0 | 家で同じ URL を開き直す（履歴から）。「部屋で見る」で自分の部屋に近いイメージと物語を読む | 自分の部屋のあの壁に掛けたら | 作品ページを後で見つけられない（共有・履歴） |
| 後日 | S0 | 作家への連絡リンクを押す | | 連絡の敷居が高い。「質問だけでも」と添える（F-24） |

**この旅で起きてほしい変化**：「かわいい小品」が「入口を手に入れる」に変わる。
**計測**：QR 読み取りから流体が流れるまでの時間。T5 まで見た割合。実物の前に戻ったか（観察）。

## J2. オンラインで絵を見る人（E）が、共有された作品ページに着く

**平日の夜。友人が SNS に貼った作品ページのリンクをスマホで開く。会場には行けない。**

| 時刻 | 場面 | 見る・する | 感じる | 離脱しそうな点 |
| --- | --- | --- | --- | --- |
| 0:00 | SNS | 投稿に絵とタイトルが出ている（OGP）。タップ | きれいな色 | 絵が出ないリンクは押されない（F-21） |
| 0:02 | S0 | 作品ページ。絵がすぐ出る。寸法「18 × 14 cm」 | 思ったより小さいんだ | 寸法の数字だけでは大きさが実感できない（P2） |
| 0:10 | S0 | 下にスクロール。「部屋で見る」。マンションのリビング、ホテルのロビー、カフェに掛かったイメージ。隅に「部屋は AI 生成のイメージ。絵は実物の写真。寸法は目安」 | あ、このくらいの大きさか。自分の部屋のあの壁 | 合成が不自然だと信用を失う（F-28）。明記が無いと「うちの絵じゃない」と誤解 |
| 0:30 | S0 | 各イメージの下の小さな物語を読む。「朝、コーヒーを淹れながらこの絵の前を通る…」。母語で | この絵がある日々、が想像できる | 物語が長い、説明っぽいと読まれない（F-29、3〜5 文） |
| 0:50 | S0 | 「入る」を押す。イヤホンをつける | | |
| 1:00 | T0〜T3 | 絵が拡大し、溶け、流れる。声が語り、文字が浮く。1〜2 分、何も操作しない | 絵の前に立ったときの「出会い」に近いものが、画面の中で起きる | 途中で通知が来て中断。一時停止と再開（F-13） |
| 3:00 | T5 | 絵に戻る。「作家に連絡」「他の作品」 | 買うとしたらこれ、と初めて思う。値段を聞きたい | 連絡先が無い、または問い合わせフォームが重い |
| 3:10 | G | 「他の作品」でギャラリーへ。5 作品が実寸比で並ぶ | もう 1 点、大きいのも見たい | |
| 翌日 | S0 | もう一度同じページを開く。物語を読み返す。連絡する | | |

**この旅で起きてほしい変化**：「いいな」で止まっていたのが、「自分の生活に置いたら」まで進む。
**計測**：体験前後の「買いたい」1〜5。連絡リンクを押した数。T5 まで見た割合。

## J3. 持ち主（A）が、買った絵と暮らす

**小品を買って 3 週間。玄関の壁に掛けている。作品カード（QR 付き）は引き出しの中。**

| 時刻 | 場面 | 見る・する | 感じる | 離脱しそうな点 |
| --- | --- | --- | --- | --- |
| 買った日 | 会場 → 家 | 絵と作品カードを持ち帰る。カードの QR を家で読み、スマホで物語モードを見る | 買った日の高揚 | |
| 1 週間後 | 家 | 毎朝、絵の前を通る。見なくなってくる | インテリアになりかけている（P3） | ここが一番の離脱点。体験に戻る理由が要る |
| 3 週間後 | 家 | 友人が来て絵をほめる。「これね、入れるんだよ」とカードの QR を見せる。友人のスマホで物語モードが流れる | 自分の絵の世界を人に見せられる。なぜこれを選んだか、話せる | 友人の端末が古くて動かない。最低限、絵と文字が出ること |
| 同じ日 | VR | 家に Quest がある。「VR で入る」。壁の小さな絵にトリガーでギュンと近づき、シュワシュワと溶けて、包まれる。奥から文字 | 自分の持っている絵の中に、自分が立っている。買った日より深い | Quest のブラウザの操作がわからない（VR の導線は会場やカードで説明） |
| 2 か月後 | 家 | 季節が変わる。物語の一節「青が緑に見える日がある」を思い出して、絵を見る | 絵が日々の彩りになっている | |
| 半年後 | S0 | 作家の次の個展の案内。ギャラリーで新作を見る。もう 1 点 | | |

**この旅で起きてほしい変化**：「絵を持つ」が「絵の世界を持つ」に変わる。週に 1 回は絵の前で止まる。
**計測**：持ち主 1 人に後日「また入りたいと思ったか」「人に見せたか」を聞く。

## J4. 母語が日本語でない来場者（D）

**日本に住むフランス語話者。日本語は少し、英語はできる。会場で小品の QR を読む。**

| 時刻 | 場面 | 見る・する | 感じる | 離脱しそうな点 |
| --- | --- | --- | --- | --- |
| 0:00 | 会場 | キャプションは日本語と英語。QR を読む | また英語で読むのか | 美術館で母語が無いときの「萎え」（USERS.md の作家の言葉） |
| 0:05 | S0 | 作品ページが**フランス語**で開く。何も選んでいない。「Entrer」 | え、フランス語だ | 自動判定が外れて英語になると、切り替えが見つからない（F-30） |
| 0:30 | T3 | 流体の奥から文字がフランス語で浮く。声は日本語。声の調子と文字が合っている | 言葉が心に入ってくる。声は作家の声として聞く | 訳が直訳で詩にならない（F-33、手直し） |
| 2:30 | T5 | 絵に戻る。物語もフランス語で読む | | |
| 後日 | SNS | フランスの友人に作品ページを共有する。友人のスマホでもフランス語で開く | 自分の国の人にも見せられる | |

**この旅で起きてほしい変化**：「日本の作家の絵」が「自分の言葉で受け取った絵」になる。
**計測**：母語と英語で見比べてもらい、どちらが「入ってきた」か。

## J5. 作家（C）が、新作を追加する

**個展の 2 週間前。新作 1 点が仕上がった。**

| 時刻 | 場面 | する | 感じる | 詰まりそうな点 |
| --- | --- | --- | --- | --- |
| 0:00 | 撮影 | 正対して撮る。長辺 2000px | | 斜めに撮ると流れ場がずれる。撮り方の 3 行を `works/README.md` に |
| 0:10 | work.json | タイトル、寸法、メッセージを日本語で 5 文。声をスマホで録る | 文を書くことで、自分がこの絵で何を見ていたかわかる | 文が長くなる。1 文 40 文字の目安 |
| 0:20 | generate | `npm run generate -- <id>`。流れ場、部屋 6 枚の合成、物語の下書き、10 言語の訳、QR | 1 コマンドで全部出る | API キーが無いと訳と物語が出ない。エラーで止まらず ja / en で進む |
| 0:25 | 確認 | PC で物語モードを見る。流れが速すぎる。`overrides.speed` を 0.3 に | 自分の絵のままだ | 何をどう直せばいいかわからない。`overrides` の説明と例 |
| 0:35 | 確認 | 物語の下書きを読む。2 本を自分の言葉に直す。英語訳を確認 | 自分の声になった | 訳を直すと再生成で消える、は避ける（F-33） |
| 0:45 | 公開 | `git push`。数分で公開 URL に出る。QR を印刷してカードに | | |
| 当日 | 会場 | 来場者がカードの QR を読んでいるのを見る | 小さい絵でも、世界が伝わっている | |

**この旅で起きてほしい変化**：作品 1 点ごとに空間を手で組む仕事が、「画像とメッセージを置く」になる。
**計測**：追加にかかった時間（目標 10 分）。`overrides` を触った回数。

## 旅の交差点（設計で押さえる点）

1. **実物に戻す**：J1 の T5 で「実物の前に戻る」導線が無いと、体験が「面白い動画」で終わる。会場では「実物の前でもう一度」の一言を出す
2. **後で見つけられる**：J1・J2 の「翌日もう一度」は、固定 URL（F-20）と共有（F-21）と履歴に頼る。作品カードに URL も印字する
3. **音なしでも成立**：J1 の会場では音を出せない。文字だけで物語が通じること。声は加点
4. **大きさの実感**：J2 で寸法の数字は効かない。「部屋で見る」が効く。合成の自然さと「AI 生成」の明記が信用の条件
5. **母語の自動判定**：J4 は判定が当たって初めて成立。外れたときの切り替えを S0 の目立つ位置に
6. **作家の手直しが消えない**：J5 の物語と訳は作家が直す前提。再生成で上書きしない
