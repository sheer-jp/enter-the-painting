# 7 日間の日程

原則：**1 作品を最後まで通してから広げる**。毎日、実機（スマホ or Quest）で 1 回は触る。

| 日 | ゴール | 主な作業 | 終わりの確認 |
| --- | --- | --- | --- |
| Day 1 | 計画確定、足場、生成 v0 | 計画レビュー。Vite + three.js の足場。`generate` の k-means 層抽出と `space.json` 出力。作品 1 点の撮影 | PC で層が奥行き違いの平面として並んで見える |
| Day 2 | PC で「入れる」 | 層を取り囲む曲面に。背景ドーム。ダイブ演出。PointerLock + WASD。仮ナレーションをスマホで録音 | PC で入口 → ダイブ → 見回しが通る。本人が「近い」と言える |
| Day 3 | VR で入る（ゴール） | WebXR セッション、VRButton、Quest で性能調整（テクスチャ・層数）。LAN の HTTPS | Quest で空間に入り 72fps 近辺 |
| Day 4 | スマホ + QR + 公開 | ジャイロ見回し（iOS 許可フロー）、タッチ補助。QR 生成。GitHub Pages に配置 | 印刷した QR を他人のスマホで読んで入れる |
| Day 5 | 声と流れ | 流れ場に沿う粒子・筆跡、視線追従。ナレーション・字幕・環境音の再生（ユーザー操作後） | 顔を動かすと筆が追ってくる。声が流れる |
| Day 6 | 2〜3 作目、仕上げ | 2 作目を `works/` に追加して 1 コマンドで通す。`overrides` で手詰め。本録音。カード印刷。Claude API 提案（余裕があれば） | 新作追加が 10 分以内でできる |
| Day 7 | 検証と提出 | 3 人以上に試してもらい記録。バグ修正。デモ動画（Quest 録画 + スマホ）。README 整備。提出 | 完成の定義 1〜6 をすべてチェック |

## マイルストーン

- **M1（Day 2 終了）**：PC で 1 作品に入れる
- **M2（Day 3 終了）**：Quest で入れる ← ゴール達成の最低ライン
- **M3（Day 4 終了）**：QR から他人のスマホで入れる、公開 URL あり
- **M4（Day 7）**：3 環境 + 声 + 2 作品以上、第三者テスト済み

## 遅れたときの優先順位

1. VR で入れること（M2）
2. スマホ QR（M3）
3. 声
4. 筆の流れの追従
5. 作品数

作品は 1 点でも提出できる。筆の追従と Claude API 提案は落としてよい。
