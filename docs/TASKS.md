# タスク分解（WBS）V2

`docs/SCHEDULE.md` の各日を、2〜4 時間のタスクに分ける。**誰**は「作家」か「Claude」（Claude Code のセッション）。作家の作業は Claude の作業と並行できるので、先に書く。
見積もりは作家 6 時間 / 日、Claude は並行して回す前提。終わったら ✓ を付け、`/log` に書く。

要件 ID は `docs/REQUIREMENTS.md`、場面は `docs/EXPERIENCE.md`。

## 並行の目安

作家の作業（撮影、メッセージ、録音、部屋の画像、訳の確認、テスト）は合計 約 20 時間。Claude の作業は約 60 時間分だが並行して回せる。作家が待つ時間を減らすため、**作家のコンテンツ作業は 1 日前倒し**で進める（Day 1 にメッセージ、Day 3 に部屋の画像、など）。
