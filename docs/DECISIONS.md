# 決定と未決定 V2

決めたことは理由つきで、未決定は期限と決め方つきで。決めたら `docs/CHANGELOG.md` にも書く。

## 決めたこと

| # | 決定 | 理由 | 日付 |
| --- | --- | --- | --- |
| 1 | VR は空間モード、PC・スマホは物語モード | VR 以外には没入が無く、空間を歩かせても流体の意味が薄い | 11-02 |
| 2 | 流体は自前の GPU シム（three.js 上） | 絵の具が流れ渦を巻く見た目は粒子より流体。既存手法（MIT）を再実装 | 11-02 |
| 3 | 絵の画像を生成モデルに入れない。部屋は AI 生成、絵は実寸合成 | 作家の絵を変えない。買う人を誤解させない | 11-02 |
| 4 | 言語は端末の言語で自動。選ばせない | 「母語でないと心に入ってこない」。選ぶ手間で没頭が途切れる | 11-02 |
| 5 | 声は日本語のみ、訳さない | 作家の声そのものが体験の一部。文字が母語で字幕の役割 | 11-02 |
| 6 | 接近は 1.2 秒でギュン | 速すぎると酔い、遅いと「ギュン」でない。初期値、実機で微調整 | 11-02 |
| 7 | 作品ページは固定 URL `/w/<id>/`、静的生成、OGP | オンラインの入口。共有されて人が来る | 11-02 |
| 8 | 連絡リンクまで。販売機能は作らない | 核は体験。買う気持ちは結果 | 11-02 |
| 9 | 翻訳・物語の下書きは生成時だけ Claude API。実行時は外部 API なし | 速さ、費用、オフラインでも動く | 11-02 |
| 10 | 環境音は Web Audio で合成 | ライセンスの心配をなくす | 11-02 |
| 11 | UI フレームワークなし、Vite + TypeScript + three.js | 画面が 4 つしかない。バンドル 300KB 以下 | 11-02 |
| 12 | ホスティングは GitHub Pages + 独自ドメイン、`base: '/'` | 静的で足りる。独自ドメインは印刷 QR の永続性のため。当てられなければ Cloudflare Pages など独自ドメインを当てられる所へ | 11-02 |
| 13 | 公開は Day 1。実機チェックは本番 URL で | Claude のセッションはクラウドで LAN サーバーを立てられない。4G 計測と OGP は公開が要る | 11-02 |
| 14 | 流体の領域は 2:1 の等距離円筒。絵は前方の矩形、残りは基調色 | 球面に貼って全方向に色があり、「流れ込む」先がある。物語モードは絵の部分を切り出す | 11-02 |
| 15 | 色の移流は MacCormack + 原画への弱い回帰 | バイリニア移流の数値拡散は「拡散 0」では防げず、3 分で構図が消える | 11-02 |
| 16 | 声は `<audio>` 要素、環境音は Web Audio | iOS のサイレントスイッチで Web Audio は消音される（要確認）。消音でも文字だけで成立 | 11-02 |
| 17 | 部屋の合成は Node でホモグラフィの逆写像。「実寸」ではなく「寸法の目安」と書く | `sharp.affine()` では台形に貼れない。AI の部屋の遠近は不正確 | 11-02 |
| 18 | 作品ページの JS は 20KB 以下、体験バンドルは「入る」後に `import()` | three.js + troika で 300KB 近く、「部屋で見るだけ」の人に落とさせない | 11-02 |
| 19 | フォントは静的 TTF、`subset-font` でビルド時に毎回サブセット | troika は woff2・可変フォントが要確認。訳や手直しの後の文字が欠けないように | 11-02 |
| 20 | 「VR で入る」は Quest のブラウザだけに出す | Android Chrome が Cardboard で immersive-vr を true にする場合がある（要確認） | 11-02 |
| 21 | 連絡はフォーム URL。コードは MIT、作品・部屋画像は作家の権利を留保 | public リポジトリに `mailto:` を書かない。権利を分ける | 11-02 |

| 22 | 最初から落とす：流れの表情切替、傾き、歩行、自動接近、環境音は `calm` 1 種、物語は 1 作品 1 本（U-12） | 日程の過密。作家「現状で OK」 | 11-03 |
| 23 | 独自ドメインは `sheerarts.com`（Cloudflare）のサブドメイン。Claude の案は `enter.sheerarts.com`（U-13） | 作家所有。印刷 QR の永続性。サブドメイン名は作家の確認待ち | 11-03 |
| 24 | VR は会場に Quest を 1 台置き、来場者に順番に体験してもらう（U-14）。M2 が最低ライン | 作家の決定 | 11-03 |

| 25 | 文字は troika を使わず、物語モードは DOM、VR は Canvas のスプライト | フォントの同梱なしで CJK が出る。S-2 の逃げ道を先に採用。VR でにじむなら troika | 11-03 |
| 26 | 作品ページとギャラリーの HTML は `generate` が作る（`w/<id>/index.html`、`index.html`）。コミットしない | 作品の追加で手作業を増やさない。Actions が作る | 11-03 |
| 27 | Vite の `base` は `./`（相対） | project site でも独自ドメインでも動く。OGP と QR だけ `BASE_URL` に依存 | 11-03 |
| 28 | VR の接近は「どのトリガーでも」始まる（絵を指していなくても） | VR で正確に指すのは難しく、止まる人を出さないため。40 秒無操作でも始まる | 11-03 |

| 29 | 流体は常時駆動で流れ続ける。駆動は目標の流れへの緩和（溜め込まない） | 作家「もっと流れ続けるイメージ」。足し続けると速度が溜まって破綻した | 11-04 |
| 30 | 物語モードの流体は絵だけの領域（最長辺 2048）、VR は等距離円筒。色場の初期値は写真のフル解像度 | 作家「画像が荒い」。等距離円筒では絵に 620×768 しか使えなかった | 11-04 |
| 31 | ページのトーンは日本の現代美術館の作法（`docs/DESIGN.md`）。明朝 + 細いゴシック、二言語併記、絵の色が滲む背景 | 作家「ギャラリーっぽく神秘的に」 | 11-04 |

| 32 | 流体の表示は線形 → sRGB に変換して出す（`colorspace_fragment`） | 作家「入った後の色が濃い」。three.js は sRGB テクスチャを線形で返すため | 11-04 |
| 33 | 終わりは「シューッと引く → 元の絵 → その絵が部屋に掛かる」 | 作家の構想。部屋の合成の四隅を space.json に残して位置を合わせる | 11-04 |
| 34 | 絵をタップしても入れる | 作家の要望 | 11-04 |
