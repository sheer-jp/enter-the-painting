# 決定と未決定 V2

決めたことは理由つきで、未決定は期限と決め方つきで。決めたら `docs/CHANGELOG.md` にも書く。

## 決めたこと

| # | 決定 | 理由 | 日付 |
| --- | --- | --- | --- |
| 1 | VR は空間モード、PC・スマホは物語モード | VR 以外には没入が無く、空間を歩かせても流体の意味が薄い | 11-02 |
| 2 | 流体は自前の GPU シム（three.js 上） | 絵の具が流れ渦を巻く見た目は粒子より流体。既存手法（MIT）を再実装 | 11-02 |
| 3 | 絵の画像を生成モデルに入れない。部屋は AI 生成、絵は実寸合成 | 作家の絵を変えない。買う人を誤解させない | 11-02 |
| 4 | 言語は端末の言語で自動。選ばせない | 「母語でないと心に入ってこない」。選ぶ手間で没頭が途切れる | 11-02 |
| 5 | 声は日本語のみ、訳さない | 作家の声そのものが体験の一部。文字が母語で字幕の役割 | 11-02 |
| 6 | 接近は 1.2 秒でギュン | 速すぎると酔い、遅いと「ギュン」でない。初期値、実機で微調整 | 11-02 |
| 7 | 作品ページは固定 URL `/w/<id>/`、静的生成、OGP | オンラインの入口。共有されて人が来る | 11-02 |
| 8 | 連絡リンクまで。販売機能は作らない | 核は体験。買う気持ちは結果 | 11-02 |
| 9 | 翻訳・物語の下書きは生成時だけ Claude API。実行時は外部 API なし | 速さ、費用、オフラインでも動く | 11-02 |
| 10 | 環境音は Web Audio で合成 | ライセンスの心配をなくす | 11-02 |
| 11 | UI フレームワークなし、Vite + TypeScript + three.js | 画面が 4 つしかない。バンドル 300KB 以下 | 11-02 |
| 12 | ホスティングは GitHub Pages | リポジトリと同じ場所。静的で足りる。OGP が効かなければ Cloudflare Pages | 11-02 |
