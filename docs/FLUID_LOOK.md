# 設計：流体に立体的な質感を（絵の具の厚みと光）V0.1

作家の狙い：流体に「もっと立体的な質感」が欲しい。WebGL の専門家の作品に近づけたい。**絵の具はアクリル。鮮やかな美しさを重視する**（11-04）。

## 0. アクリル絵の具の見え方（油絵の具との違い）

| | アクリル（この作品） | 油絵の具 |
| --- | --- | --- |
| 光沢 | 乾くとサテン〜半つや消し。ハイライトは小さく締まる | 濡れたような強い光沢、広いハイライト |
| 色 | 鮮やかで濁らない。色の境がはっきり | 混ざって深い、黄味を帯びる |
| 厚み | 盛り上がりは残るが稜線がシャープ。筆の跡がくっきり | なだらかで溶け合う |
| 乾き | 速い。流れが止まると形が固定される感じ | ゆっくり |

→ 設計への反映：鏡面反射は**小さく鋭く**（指数 96、強さ 0.18）、広い光沢や黄味の映り込みは入れない。環境の映り込みは白い窓の光をごく薄く（0.08）。**色は常に鮮やかさ優先**：陰影で暗くなる分は彩度と明るさの補正で戻し、陰影は稜線の近くだけに出す（レリーフの陰影の幅を狭く）。流れが収まる場面（T4）では厚みの稜線を少し鋭くして「乾いた」感じに。
今の流体は色が平らに流れている（染料のシミュレーション）。立体感は「絵の具に厚みがあり、光が当たっている」ことから生まれる。設計してから実装する。

## 1. 何が立体感をつくるか（プロの作品に共通する要素）

| 要素 | 効果 | 実装の重さ |
| --- | --- | --- |
| **厚み（レリーフ）と法線** | 絵の具の盛り上がりの陰影。筆のあとが光を受ける。これが最も効く | 中（厚みの場を 1 枚追加、法線は勾配） |
| **鏡面反射（サテンの小さな光）** | 盛り上がりの稜線に小さく締まったハイライト。アクリルの乾いた光沢 | 小（シェーダ 1 式） |
| **環境の映り込み（ごく薄く）** | 白い窓の光が表面にかすかに映る。ギラつかせない | 小（2D の環境テクスチャ） |
| **流れに沿う筋（異方性）** | 筆のストロークのような細い筋が流れ方向に出る | 中（流れ場に沿ったノイズ） |
| **触れたときの凹み** | 指で押した場所が凹んで盛り上がる。関与の手応え | 小（タッチで厚みを加減） |
| **仕上げ（フィルム感）** | 控えめなブルーム、粒子、周辺減光。色が「画面の色」から「光」になる | 小（後処理 1 パス） |
| 厚みの保存と移流 | 厚みが流れと一緒に運ばれ、ぶつかる所で盛り上がる | 中（厚みも MacCormack で移流） |

やらないこと：本物の 3D メッシュ化（重い。VR で 72fps が厳しい）、レイトレース、粒子を 10 万個（Quest で無理）。すべて 2D の場で「高さ」を持たせ、シェーディングで立体に見せる（絵の具のレリーフは浅いので、この方法で十分）。

## 2. 仕組み

```
色場 dye（今ある）           … 絵の具の色
厚み場 thick（新しく追加）   … 絵の具の高さ 0〜1
速度場 vel（今ある）

毎フレーム：
  thick を vel で移流（MacCormack）。収束する所で少し増え、発散する所で減る（div から）
  触れた場所：押した瞬間は凹み（−）、指の軌跡の両脇は盛り上がり（+）
  原画への回帰：厚みも「原画の厚み」へ弱く戻る（構図が残るのと同じ理由）

表示：
  normal = normalize(−dThick/dx × relief, −dThick/dy × relief, 1)
  diffuse = 色 × (0.75 + 0.25 × dot(normal, light))
  specular = pow(max(dot(normal, half), 0), 96) × gloss × 環境の明るさ   … アクリル：小さく鋭く
  env = 環境テクスチャを normal で引く（白い窓の光）× 0.08
  陰影は稜線の近くだけ（normal の傾きが大きい所）。平らな所の色は原色のまま
  色 = diffuse + specular + env → 彩度補正 → ブルーム → 粒子 → 周辺減光 → sRGB
```

- **原画の厚み**：絵の写真から作る。明度の高周波（筆のあと）と、`flow.png` の強さ（筆致の密度）から `relief.png` を生成時に出す（`generate` に 1 手順追加）。筆のあとがある場所は最初から盛り上がっている
- **光の向き**：画面の左上やや手前。物語モードでは 1 分で 20° ほどゆっくり動く（生きている感じ）。VR では頭の向きに対して固定（頭を振ると光沢が走る）
- **触れる**：今の `splat`（速度）に加えて、厚みに `−` の splat（押す）と、指の軌跡の両脇に `+`（絵の具が指の脇に寄る）。タップの波紋は厚みにも輪を立てる
- **パラメータ**（`space.json` の `fluid.look`、`overrides` で作品ごとに）：`relief`（0〜1、既定 0.5）、`gloss`（0〜1、既定 0.18）、`sharpness`（鏡面の指数、既定 96）、`bloom`（0〜0.5、既定 0.08）、`grain`（0〜0.1、既定 0.02）、`vivid`（彩度の補正、既定 0.35。今の実装の値）

## 3. 見た目の目標（確認の基準）

- 静止したとき、絵の筆のあとに薄い陰影が見える（レリーフ）。写真より少し「物」に見える
- 流れているとき、盛り上がりの稜線に光が走り、流れの向きに細い筋が出る
- 指でなぞると、絵の具を押しのけた溝と、両脇の盛り上がりが見える
- ギラつかない。光沢は「乾いたアクリル」のサテン。油絵の具にも、プラスチックにも見えない
- **色の鮮やかさは絶対に落とさない**。陰影は稜線の近くだけ、平らな所は原色のまま。暗くなる分は彩度と明るさの補正で戻す。作家が「鮮やかさが落ちた」と言ったら、質感より色を優先して戻す
- Quest で 72fps を保つ（追加は厚みの移流 3 パス + 表示 1 パス。品質 medium では厚みの解像度を色場の半分に）

## 4. 段階

| 段階 | 内容 | 確認 |
| --- | --- | --- |
| 1 | 厚み場 + 法線 + 拡散反射 + 鏡面反射（光は固定） | 静止画で筆のあとに陰影。流れて稜線に光 |
| 2 | 厚みの移流と、収束・発散での増減。原画の厚みへの回帰 | 流れに厚みが乗って運ばれる。3 分後も筆のあとが残る |
| 3 | 触れたときの凹みと盛り上がり | なぞった溝が見える |
| 4 | 環境の映り込み、動く光、仕上げ（ブルーム・粒子・周辺減光） | ギラつかず、画面の色が光に見える |
| 5 | VR（球面）で同じシェーディング。頭の向きで光沢が動く | Quest で 72fps |

段階 1〜2 で立体感は出る。3〜5 は仕上げ。作家が段階 1 を見てから方向を決める。

## 5.5 入りの「渦に吸い込まれる」との関係

入りの演出（`docs/EXPERIENCE.md` の T1〜T2 の設計変更）は、この質感と同じ流体に `vortex`（中心へ向かう回転 + 吸い込み）を足すだけ。厚み場があると渦の中心が凹んで見え、吸い込まれる感じが強くなる。段階 1〜2 と一緒に実装する。

## 6. 決まったこと（11-04）

- 絵の具はアクリル。光沢はサテンの小さなハイライト。鮮やかさ優先
- 段階 1〜2（厚みと光、流れに乗る厚み）と入りの渦を先に作り、作家が見てから 3〜5 へ
