# 絵はどこに飾られるか（日本の住宅、調べたこと）V0

2026-11-04、作家の指示「絵を買った人がどこに置くかをちゃんと考える。日本と仮定する」で調べたもの。部屋の画像の場面と、掛ける高さの根拠にする。

## 1. 建具と部屋の寸法（縮尺の基準）

結論：**室内ドア 200 cm は、2000 年代以降の住宅では妥当**（枠で 202 cm）。古い住宅なら 180〜190 cm。部屋の画像は新しめの内装なので 200 cm を基準にする。`rooms/REFERENCES.json` は 200 のまま、`door_interior_old`（185 cm）を足して古い内装の部屋で使えるようにする。

## 2. 掛ける高さ（日本の目安）

- **絵の中心を床から 145 cm** が日本で広く言われる目安（「145 の法則」）。立ったときの目線の高さ。記事により 145〜150、145〜155 とも（[Re:CENO](https://www.receno.com/feature/art/decorate.php)、[trill](https://trilltrill.jp/articles/4700914)、[kajikissa](https://kajikissa.com/art/)）
- **座って見る場所**（ソファの前、食卓、寝室）は少し低く、**中心 135〜140 cm**（[poppy quest](https://poppy-quest.com/2026/07/03/office-art-hang-guide/)）
- **家具の上に掛けるとき**は、家具の上端から **15〜25 cm** 空ける（こぶし 1〜2 個）（[Re:CENO](https://www.receno.com/feature/art/decorate.php)）
- **リビングの壁**では、絵の幅は壁幅の 7〜8 割に収まるのが目安。余白が大事（[izutsuya](https://izutsuya.art/)）

→ 変更：掛ける高さの既定を 150 → **145 cm**。座って見る部屋（ソファの前、寝室、食卓）は **138 cm**。机や棚の上は「家具の上端 + 20 cm が絵の下端」で決める。

## 3. どこに飾るか（日本の住宅で実際に多い場所）

購入者の統計は見つからなかった（画廊や販売店のガイドが中心）。ガイドに共通する場所と、向く大きさ：

| 場所 | 誰が、いつ見るか | 向く大きさ | 備考 |
| --- | --- | --- | --- |
| **玄関**（靴箱の上、正面の壁） | 帰宅時、来客の出迎え。立って、短く | 小〜中（F0〜F8、長辺 18〜45 cm） | 「出迎えの場、小〜中の明るい作品」（[from-artist](https://from-artist.com/en/blogs/)）。玄関は日本の住宅で最も「絵を飾る場所」として挙がる |
| **リビングのソファの上の壁** | 家族と来客。座って、長く | 中〜大（F8〜F30、長辺 45〜90 cm） | ソファの幅との釣り合い。「壁幅の 7〜8 割まで」 |
| **サイドボード・テレビ台の上** | 立っても座っても | 小〜中 | 家具の上端から 15〜25 cm 空ける |
| **寝室（ベッドの横、ヘッドボードの上）** | ひとり。寝る前、起きたとき | 小〜中（F3〜F10） | 落ち着いた色。横になって見るので低め |
| **廊下の突き当たり、階段** | 通りすがり。立って | 小（F0〜F6）を 1〜3 点 | 細長い壁。小品の定位置 |
| **ダイニングの壁** | 食事のとき。座って | 小〜中 | 中心 135〜140 |
| **書斎・ワークスペースの机の上** | ひとり。座って | 小（F0〜F4） | 机の上端 + 20 cm |
| **床の間**（和室） | 来客 | 小〜中、掛け軸の代わり | 和室がある家では今も現役 |
| **一人暮らしのワンルーム** | ひとり。机の上、ベッド脇、棚の上、玄関 | 小（F0〜F4） | 壁が少なく、家具の上が主な場所 |

多くの購入者は「どこに飾るかを決めてから買う」（[いつき美術画廊](https://itsukiart.com/column/7/)）。だから「部屋で見る」は**買う前に、自分の家のその場所を思い浮かべる**ための道具。場所の名前（玄関、ソファの上、ベッド脇）で見せるのが正しい。

## 4. 部屋の画像の場面を、飾る場所に合わせて組み直す

今ある画像（リビング 4、玄関 1、一人暮らし 5）は「空いた壁」で、実際の飾る場所に近いのは「ソファの向かいの壁」「机の上」「ベッド脇」。足りないのは、日本で最も多い **玄関の靴箱の上**、**ソファの上の壁（座って見る）**、**サイドボードの上**、**廊下の突き当たり**、**床の間**。プロンプトを `rooms/PROMPTS.md` の「飾る場所の実例」に追加する。

作品の大きさで場面を選ぶ：

| 作品 | 広い家 | 一人暮らし |
| --- | --- | --- |
| F15（53 × 65）以上 | ソファの上の壁、ダイニングの壁 | 机の上、ベッド脇（存在感が出る） |
| F4〜F10 | 玄関の靴箱の上、サイドボードの上、寝室 | 机の上、棚の上 |
| F0〜F3（手のひら大） | 廊下、玄関の棚、床の間 | 棚の上、キッチン、玄関 |

## 5. 縮尺と高さに反映すること

- `hang.center_from_floor_cm`：立って見る壁 145、座って見る場所 138。家具の上に掛けるときは **`hang.furniture_top_y_px`（家具の上端の画素）+ `gap_cm`（既定 20）** で下端を決める（11-04 変更：床の線から cm で決めると、家具が壁より手前のときや床の線の読み違いで浮いて見えた。ローボードの部屋で 62 cm 浮いていた）。`bottom_from_floor_cm` も残す
- `rooms/REFERENCES.json`：`door_interior` 200（枠 202）、`door_interior_old` 185、`ceiling` 240、`ceiling_old` 230、`sofa_2seat` 高さ 80 / 幅 160、`shoe_cabinet` 高さ 90、`sideboard` 高さ 80、`dining_table` 高さ 72、`bed_single` 幅 100 / マットレス上端 50、`headboard` 高さ 90
