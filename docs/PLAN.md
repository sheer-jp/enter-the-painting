# 計画：抽象画の中に入りこめる・デジタルギャラリー

## 1. 作りたいものと理由

私は抽象画を描く作家です。大きな作品の前に立つと、人は絵の中に入り込んで没頭してくれる。
しかし小さな作品では、平面の手のひらほどの絵から、その奥にある世界観を伝えるのがとても難しい。

一方で、大きな絵を置ける家は多くない。個展で「本当は買いたいけど家には飾れない」と何度も言われた。
多くの人が持てるのは小さな絵。小さな絵を持つ人にも、その絵につながる広い世界を感じてほしい。

絵の具の手触りがある実物と、奥行きを作れるデジタルを掛け合わせる。
手元の絵が入口で、その先にデジタルの世界が広がる。
試作は重ねてきたが「絵の中に入る」ところまでは形にできていない。この 1 週間でそこを作る。

## 2. 誰の、どんな困りごとを解くか

- **誰**：小さな作品を手にした人（購入者、個展の来場者）と、小さな作品で世界観を伝えたい作家
- **困りごと**：抽象画の没頭は、視界の端から端までを絵が満たすことで生まれる。小さな作品は視界のごく一部にしかならず、同じ没頭が起きにくい。作家は言葉で補うしかなく、持ち主は「この絵の向こうに何があるのか」を感じる手段がない。小さな絵はインテリアとして消費されやすい。
- **同じことがオンラインではもっと強く起きる**：大作も小品もサムネイルになり、寸法も手触りも奥行きも落ちる。価値が伝わらず、買う気持ちにならない。課題を一言で言うと「絵の『世界』が伝わらない場面が 3 つある。会場の小さな絵、オンラインの絵、買ったあとの絵」。整理は `docs/USERS.md` の冒頭
- **解き方**：「奥行き」。小さな絵でも、その絵の世界に奥行きを持たせて視界いっぱいに広げれば、大きな絵の前に立つときと同じ没頭を小さな画面でも起こせる。絵の奥にある物語ごと味わえる体験にし、買い手がその絵を自分の記憶や経験と重なるものとして持ち続けられるようにする。

## 3. 体験の流れ（ユーザーストーリー）

一言で：**手元の絵に近づくと、絵が流体になって自分の全部を包む。奥から文字がふんわり浮いてきて、母語でメッセージを読める。**
場面ごとの仕様と数値は `docs/EXPERIENCE.md`。

入口は 2 つ。会場では作品の QR を読んで、その絵のページに直接着く。オンラインではギャラリーで 5 作品から選ぶ。着く先は同じ作品ページ。

1. 作品ページを開く。手元の絵が実物の寸法で表示される。「入る」を押す（ここで音・ジャイロ・VR の許可を取る）
2. 薄暗い空間の壁に、小さな絵が掛かっている。絵をタップ（クリック、VR ではトリガー）すると、そこにギュンと近づく。歩いて近づいてもよい
3. 1m を切ると、絵の表面が流体になる。絵の具が筆致の方向に流れ出す
4. 流体になった絵がふくらんで、上下左右、背後まで自分の全部を包む
5. 視線の先の奥から、作家のメッセージが 1 文ずつふんわり浮いてきて、読める距離で止まり、溶ける。文字は閲覧者の母語。作家の声（日本語）が同じ文を語る
6. 「戻る」と流体が縮んで壁の小さな絵に戻る。「あの小さい絵の中に、今のがあった」

3 つの入り方：

| 環境 | 入力 | 位置づけ |
| --- | --- | --- |
| VR ヘッドセット（Meta Quest のブラウザ） | WebXR immersive-vr、頭の向き + コントローラ | **ゴール**。全身で入る |
| パソコン | マウスで見回し、絵をクリックで接近（WASD でも歩ける） | 制作確認・デモに使う |
| スマホ | 端末の向き（ジャイロ）で見回し、絵をタップで接近 | 来場者が一番使う入口 |

## 4. 1 週間で作る試作品

- 自分の実作品 5 点で、絵の色・筆致・構図から「入れる空間」を作る（ブラウザで動く WebXR、インストール不要）
- 近づくと絵が流体になって全身を包む。奥から作家のメッセージが文字で浮いてくる
- 同じ空間に 3 つの入り方（VR / PC / スマホ）を用意する
- 入口は 2 つ。会場の QR（作品ページ直行）と、オンラインギャラリー（5 作品から選ぶ）
- 文字と UI は閲覧者の母語。日本語・英語を基本に 10 言語。声は日本語のみ（作家の声）。日本語以外の人には、声は日本語のまま、文字が母語
- 空間の中に作家の声（制作の背景）と音を置く

### Claude Code に任せる部分

- 絵の画像から空間のパラメータ（色・筆致の流れ・動き）を起こす処理の設計と実装
- 流体シミュレーションと「平面 → 包む球面」の変形、文字の浮上演出
- VR / PC / スマホの 3 環境での入力と表示の切り替え
- 作品ごとの空間を定義ファイル 1 つで追加できる仕組み、メッセージの 10 言語への翻訳

### 自動化する作業

作品 1 点ごとに手作業で空間を組んでいたところを、**画像と短い作家メモを置くだけ**で空間と QR が生成されるようにする。

```
works/<id>/painting.jpg + work.json（メッセージ数行） → npm run generate → 流れ場 + 10 言語の文字 + 作品ページ + QR
```

### やらない（今回は）

- ネイティブアプリ、App Store 配布
- ログイン、購入機能、NFT
- 画像生成 AI による絵の「続き」の生成（作家の絵そのものを使う。生成で絵を変えない）
- iOS Safari での WebXR（非対応。ジャイロモードで代替）
- 右から左に書く言語（アラビア語など）。文字描画の対応が必要
- 実行時の翻訳 API 呼び出し（訳はすべて生成時に作って埋め込む）

### 将来（今回はやらないが、設計で邪魔しない）

- **NFC タグ**：作品カードや額の裏に NFC タグを貼り、スマホをかざすと作品ページが開く。タグに URL（NDEF）を書くだけで iPhone（XS 以降）も Android もアプリなしで開ける。QR と同じ URL を指すので、アプリ側の追加実装は不要。古い機種では読めないため QR が本線、NFC は追加
- 持ち主ごとの「自分の記憶」をメッセージに足せる（持ち主が文を書き、同じ空間に浮く）
- 英語以外の声（作家の録音、または作家の声の合成）

## 6. 完成の定義

「自分の小さな作品を持つ人に、手元の機材（VR / PC / スマホのどれでも）でその絵の中に入ってもらえること」。
次の個展で、来場者が会場の作品の QR から実際に入れる状態で展示する。

具体的な受け入れ条件：

1. 印刷した QR を初めて見る人のスマホで読み、30 秒以内に絵が流体になって包まれる
2. Meta Quest のブラウザで同じ URL を開き、包まれたあと頭をどの方向に向けても絵の色がある
3. PC のブラウザで同じ URL を開き、歩いて近づき、マウスで見回せる
4. 包まれたあと、作家の声が流れ、奥から文字が浮いてきて読める。英語設定の端末では何も選ばずに英語で出る
5. オンラインギャラリーに 5 作品が並び、どれを選んでも同じ体験ができる
6. 新しい作品を `works/` に画像とメッセージを置いて 1 コマンドで追加できる
7. 作家本人が「これは自分の絵の中だ」「包まれた」と感じる（主観評価。最重要）

## 7. 評価のしかた

- 作家本人の主観評価（7 を 1〜5 で記録、作品ごと）
- 周囲 3 人以上に 3 環境のいずれかで試してもらい、「入れた感じがしたか」を聞く
- QR 読み取りから空間表示までの時間（スマホ、4G 回線で計測）
