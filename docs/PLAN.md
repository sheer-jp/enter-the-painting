# 計画：抽象画の中に入りこめる・デジタルギャラリー

## 1. 作りたいものと理由

私は抽象画を描く作家です。大きな作品の前に立つと、人は絵の中に入り込んで没頭してくれる。
しかし小さな作品では、平面の手のひらほどの絵から、その奥にある世界観を伝えるのがとても難しい。

一方で、大きな絵を置ける家は多くない。個展で「本当は買いたいけど家には飾れない」と何度も言われた。
多くの人が持てるのは小さな絵。小さな絵を持つ人にも、その絵につながる広い世界を感じてほしい。

絵の具の手触りがある実物と、奥行きを作れるデジタルを掛け合わせる。
手元の絵が入口で、その先にデジタルの世界が広がる。
試作は重ねてきたが「絵の中に入る」ところまでは形にできていない。この 1 週間でそこを作る。

## 2. 誰の、どんな困りごとを解くか

- **誰**：小さな作品を手にした人（購入者、個展の来場者）と、小さな作品で世界観を伝えたい作家
- **困りごと**：抽象画の没頭は、視界の端から端までを絵が満たすことで生まれる。小さな作品は視界のごく一部にしかならず、同じ没頭が起きにくい。作家は言葉で補うしかなく、持ち主は「この絵の向こうに何があるのか」を感じる手段がない。小さな絵はインテリアとして消費されやすい。
- **解き方**：「奥行き」。小さな絵でも、その絵の世界に奥行きを持たせて視界いっぱいに広げれば、大きな絵の前に立つときと同じ没頭を小さな画面でも起こせる。絵の奥にある物語ごと味わえる体験にし、買い手がその絵を自分の記憶や経験と重なるものとして持ち続けられるようにする。

## 3. 体験の流れ（ユーザーストーリー）

1. 作品カードやキャプションの QR をスマホで読む（または URL を開く）
2. 手元の絵が画面いっぱいに表示される（入口）。「入る」ボタンを押す
3. 絵がゆっくり奥に開き、色の層が奥行きを持って自分を取り囲む（ダイブ演出、約 5〜8 秒）
4. 顔（端末・マウス・ヘッドセット）を動かすと、筆の流れが視線を追いかけてくる
5. 作家の声が制作の背景を語り始める。環境音が空間を満たす
6. 好きなだけ空間に居て、戻るとギャラリー（作品一覧）へ

3 つの入り方：

| 環境 | 入力 | 位置づけ |
| --- | --- | --- |
| VR ヘッドセット（Meta Quest のブラウザ） | WebXR immersive-vr、頭の向き + コントローラ | **ゴール**。全身で入る |
| パソコン | マウスで見回し、WASD で歩く | 制作確認・デモに使う |
| スマホ | 端末の向き（ジャイロ）で見回し、指で補助 | 来場者が一番使う入口 |

## 4. 1 週間で作る試作品

- 自分の実作品 1〜3 点で、絵の色・筆致・構図から「入れる空間」を作る（ブラウザで動く WebXR、インストール不要）
- 同じ空間に 3 つの入り方（VR / PC / スマホ）を用意する
- 絵ごとに QR を発行し、読み取るとその絵の空間が開く
- 空間の中に作家の声（制作の背景）と音を置く

### Claude Code に任せる部分

- 絵の画像から空間のパラメータ（色・奥行き・動き）を起こす処理の設計と実装
- VR / PC / スマホの 3 環境での入力と表示の切り替え
- 作品ごとの空間を定義ファイル 1 つで追加できる仕組み

### 自動化する作業

作品 1 点ごとに手作業で空間を組んでいたところを、**画像と短い作家メモを置くだけ**で空間と QR が生成されるようにする。

```
works/<id>/painting.jpg + work.json（メモ数行） → npm run generate → 空間レイヤー + QR
```

## 5. スコープ

### やる（必須）

- [ ] 画像 1 枚 → 色の層（4〜8 層）と筆の流れ場を自動抽出
- [ ] 層を奥行きのある空間（視点を中心に取り囲む曲面）として表示
- [ ] 入口の絵から空間へのダイブ演出
- [ ] PC（マウス + WASD）、スマホ（ジャイロ + タッチ）、VR（WebXR）の 3 モード自動切替
- [ ] 視線の向きに筆の流れが追従する動き
- [ ] 作家の音声ナレーション + 環境音（ユーザー操作後に再生）
- [ ] 作品ごとの QR 生成と、URL `?w=<id>` で空間が開くルーティング
- [ ] HTTPS でホスティング（WebXR とジャイロの要件）
- [ ] 実作品 1 点で、本人以外の人に 3 環境で入ってもらえる

### やれたらやる（余裕があれば）

- [ ] 実作品 3 点まで増やす
- [ ] VR コントローラで前後に進む、手を伸ばして層に触れると波紋が出る
- [ ] 作家メモから字幕テキスト・環境音プリセット・動きの速さを Claude API で提案
- [ ] ギャラリー画面（作品一覧）
- [ ] 鑑賞の滞在時間などの簡単な記録

### やらない（今回は）

- ネイティブアプリ、App Store 配布
- ログイン、購入機能、NFT
- 画像生成 AI による絵の「続き」の生成（作家の絵そのものを使う。生成で絵を変えない）
- iOS Safari での WebXR（非対応。ジャイロモードで代替）

## 6. 完成の定義

「自分の小さな作品を持つ人に、手元の機材（VR / PC / スマホのどれでも）でその絵の中に入ってもらえること」。
次の個展で、来場者が会場の作品の QR から実際に入れる状態で展示する。

具体的な受け入れ条件：

1. 印刷した QR を初めて見る人のスマホで読み、30 秒以内に絵の空間に入れる
2. Meta Quest のブラウザで同じ URL を開き、ヘッドセットで空間に入れる
3. PC のブラウザで同じ URL を開き、マウスで見回せる
4. 空間に入ると作家の声が流れ、顔を動かすと筆の流れが追ってくる
5. 新しい作品を `works/` に画像とメモを置いて 1 コマンドで追加できる
6. 作家本人が「これは自分の絵の中だ」と感じる（主観評価。最重要）

## 7. 評価のしかた

- 作家本人の主観評価（6 を 1〜5 で記録、作品ごと）
- 周囲 3 人以上に 3 環境のいずれかで試してもらい、「入れた感じがしたか」を聞く
- QR 読み取りから空間表示までの時間（スマホ、4G 回線で計測）
