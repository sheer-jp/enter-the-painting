# 計画 V2：抽象画の中に入りこめる・デジタルギャラリー

V1 との差分は `docs/CHANGELOG.md`。V1 の初版はコミット `530bcde`、V2 直前は `9cec3ee`。

## 1. 背景（作家の言葉）

私は抽象画を描く作家です。大きな作品の前に立つと、人は絵の中に入り込んで没頭してくれる。
しかし小さな作品では、平面の手のひらほどの絵から、その奥にある世界観を伝えるのがとても難しい。

一方で、大きな絵を置ける家は多くない。個展で「本当は買いたいけど家には飾れない」と何度も言われた。
多くの人が持てるのは小さな絵。小さな絵を持つ人にも、その絵につながる広い世界を感じてほしい。

絵の具の手触りがある実物と、奥行きを作れるデジタルを掛け合わせる。
手元の絵が入口で、その先にデジタルの世界が広がる。
試作は重ねてきたが「絵の中に入る」ところまでは形にできていない。この 1 週間でそこを作る。

## 2. 課題

**絵の「世界」が伝わらない場面が 3 つある。会場の小さな絵、オンラインの絵、買ったあとの絵。**

| | 場面 | 何が落ちるか | 結果 |
| --- | --- | --- | --- |
| P1 | 会場の小さな絵 | 視界を満たす大きさ | 没頭が起きない。「かわいい」止まり。作家は言葉で補うしかない |
| P2 | オンラインの絵 | 寸法、手触り、奥行きのすべて。大作も小品もサムネイルになる | 価値が伝わらない。「いいな」で止まり、買う気持ちにならない |
| P3 | 買ったあとの絵 | 買った日の気持ち | 部屋のインテリアになり、「この絵の向こう」に行く手段がない |

抽象画は「何が描いてあるか」で引っ張れないぶん、P2 は特に強く起きる。
人がオンラインで絵を買えない理由は「大きさがわからない」「手触りがわからない」「絵の前に立ったときの出会いの瞬間がない」「作家の話を聞いていない」の 4 つ。この試作が埋めるのは後ろの 2 つと、大きさの一部。手触りは埋めない（手触りは実物、世界はデジタル、という分担）。

**順番**：核は「絵の中に入る」体験。買う気持ちはその結果として起きるもの。販売ツールにしない。

## 4. 解き方と体験

解き方は「奥行き」。小さな絵でもサムネイルでも、その絵の世界に奥行きを持たせて視界いっぱいに広げれば、大きな絵の前に立つときと同じ没頭を起こせる。

一言で：

- **VR**：絵にギュンと近づくと、シュワシュワと溶けて、気づいたら自分の全体が絵の流体に包まれている。声と文字が流れてくる
- **PC・スマホ**：絵が画面いっぱいになり、流体のアニメーションが流れる。作家の声と文字で、物語のように語られる（物語モード）
- **作品ページ**：家やホテル、いろいろな場所に置かれたイメージと、その絵のある日々を描いた小さな物語で、「自分の生活に置いたら」が想像できる

VR 以外には没入が無いので、空間を歩かせても流体の意味が薄い。だから VR は「空間」、他は「映像」。流体とメッセージは同じものを使う。

入口は 2 つで対等。会場では作品の QR を読んで作品ページに直接着く。オンラインではギャラリーで 5 作品から選ぶ、または共有された作品ページの URL を開く。着く先は同じ作品ページ。

1. 作品ページを開く。絵がすぐ表示される。寸法・技法・年。「部屋で見る」で家やホテルに置かれたイメージと小さな物語。作家への連絡先、共有。「入る」を押す（ここで音・ジャイロ・VR の許可を取る）
2. **VR**：薄暗い空間の壁に、小さな絵が実物の寸法で掛かっている。絵にトリガーでギュンと近づく。1m を切ると縁からシュワシュワと溶けて、絵の具が筆致の方向に流れ出す。流体がふくらんで、上下左右、背後まで自分の全部を包む。視線の先の奥から、作家のメッセージが 1 文ずつふんわり浮いてきて、読める距離で止まり、溶ける。作家の声（日本語のみ）が同じ文を語る。「戻る」と壁の小さな絵に戻る
3. **PC・スマホ**：絵が画面いっぱいにギュンと拡大し、縁からシュワシュワと溶けて流体になる。流れ続ける流体の奥から文字が浮き、作家の声が物語のように語る。1〜3 分で絵に戻る
4. どちらも文字は閲覧者の母語。終わると作品ページに戻り、連絡先と他の作品がある。「あの小さい絵の中に、今のがあった」

場面ごとの仕様と数値は `docs/EXPERIENCE.md`。要件の一覧は `docs/REQUIREMENTS.md`。

3 つの入り方：

| 環境 | 入力 | 位置づけ |
| --- | --- | --- |
| VR ヘッドセット（Meta Quest のブラウザ） | 空間モード。頭の向き、絵にトリガーで接近 | **ゴール**。全身で入る |
| パソコン | 物語モード。クリックで一時停止、Esc で閉じる | オンラインの入口のひとつ。デモ動画の土台 |
| スマホ | 物語モード。タップで一時停止。傾きで流れが寄る（推奨） | 会場でもオンラインでも一番使われる入口 |

## 5. 1 週間で作る試作品（MVP）

- 自分の実作品 5 点で、絵の色・筆致から「入れる空間」を作る（ブラウザで動く WebXR、インストール不要）
- VR では近づくと絵が流体になって全身を包む。PC・スマホでは流体のアニメーションと声と文字の物語モード。奥から作家のメッセージが文字で浮いてくる
- 作品ページに「部屋で見る」：AI 生成の家・ホテル・カフェなどに、実物の絵を実寸で合成したイメージ 6〜10 枚と、その絵のある日々を描いた小さな物語
- 入口は 2 つ。会場の QR と、オンラインギャラリー。作品ごとに固定ページ `/w/<id>/`。共有すると絵とタイトルが出る
- 文字と UI は閲覧者の母語。日本語・英語を基本に 10 言語。声は日本語のみ
- 作品ページに作家への連絡先（リンク 1 つ）。買う気持ちを測る入口であり、販売機能ではない
- 空間の中に作家の声と音

### Claude Code に任せる部分

- 絵の画像から空間のパラメータ（色・筆致の流れ・動き）を起こす処理の設計と実装
- 流体シミュレーションと「平面 → 包む球面」の変形、物語モードの進行、文字の浮上演出
- VR は空間、PC・スマホは映像、の切り替え
- 作品ごとの空間・物語・作品ページ・部屋のイメージを定義ファイル 1 つで追加できる仕組み、メッセージと小さな物語の 10 言語への翻訳、小さな物語の下書き

### 自動化する作業

作品 1 点ごとに手作業で空間とページを組んでいたところを、**画像とメッセージを置くだけ**で空間・作品ページ・10 言語の文字・QR が生成されるようにする。

```
works/<id>/painting.jpg + work.json（メッセージ数行） → npm run generate → 流れ場 + 翻訳 + 部屋の合成 + 物語の下書き + 作品ページ + QR
```

## 6. スコープ

優先度つきの一覧は `docs/REQUIREMENTS.md`。ここでは境界だけ。

### やる（必須）

- 絵を流体にして、VR では近づくと溶け、包まれ、文字が浮く（S1〜S5）
- PC・スマホでは物語モード（T0〜T5）。流体のアニメーション、文字、声
- 作品ページ `/w/<id>/`（5 作品、OGP 付き）とギャラリー `/`、QR
- 「部屋で見る」：AI 生成の部屋 6 枚以上に実物の絵を実寸で合成。「部屋は AI、絵は実物」と明記
- 開いた瞬間に絵が見える（JS を待たない）。4G で 5 秒以内に「入る」が押せる
- 日本語・英語の文字と UI。端末の言語で自動選択
- 作家の声（日本語）と環境音。作家への連絡リンク
- HTTPS で公開。実作品 5 点で、本人以外の人に 3 環境で入ってもらえる

### やれたらやる

- 残り 8 言語（中国語 簡体・繁体、韓国語、フランス語、ドイツ語、スペイン語、イタリア語、ポルトガル語）
- 「部屋で見る」の各イメージに小さな物語（3〜5 文、作家の声、10 言語）
- 部屋を 10 枚に増やす
- スマホの傾きで流れが寄る
- 「入った」「文字を最後まで見た」「連絡先を押した」の回数の記録（Cookie なしの計測）
- VR で手を伸ばして流体に触れると渦が起きる
- 「拡大しただけ」と「流体で包む」の切替フラグ（仮説 1 の検証用）

### やらない（今回は）

- ネイティブアプリ、App Store 配布
- ログイン、決済、カート、NFT。販売機能全般（連絡リンクまで）
- 絵の画像を画像生成 AI に入れること（img2img、インペイント）。部屋は AI で作ってよいが、絵は実物の写真を実寸で合成する。生成で絵を変えない
- PC・スマホで空間を歩く・見回す（没入が無いので意味が薄い。VR だけ）
- iOS Safari での WebXR（非対応。ジャイロモードで代替）
- 右から左に書く言語（アラビア語など）
- 実行時の翻訳 API 呼び出し（訳はすべて生成時に作って埋め込む）
- 声の翻訳・合成。声は作家の日本語のみ

- 持ち主ごとの「自分の記憶」をメッセージに足せる（持ち主が文を書き、同じ空間に浮く）

## 7. 完成の定義

「自分の小さな作品を持つ人に、手元の機材（VR / PC / スマホのどれでも）でその絵の中に入ってもらえること」。
次の個展で、来場者が会場の作品の QR から実際に入れる状態で展示する。あわせて、会場に来られない人がオンラインギャラリーから同じ体験に入れる。

受け入れ条件：

1. 印刷した QR を初めて見る人のスマホで読み、30 秒以内に絵が流体になって流れ、声と文字が始まる
2. Meta Quest のブラウザで同じ URL を開き、包まれたあと頭をどの方向に向けても絵の色がある
3. PC のブラウザで同じ URL を開き、「入る」から何も操作せずに物語モードが最後まで流れる
4. 作家の声が流れ、奥から文字が浮いてきて読める。英語設定の端末では何も選ばずに英語で出る
5. オンラインギャラリーに 5 作品が実寸比で並び、どれを選んでも同じ体験ができる。作品ページを SNS に貼ると絵とタイトルが出る。「部屋で見る」で 6 枚以上のイメージが実寸で出る
6. 作品ページを 4G で開いて 2 秒以内に絵が見え、5 秒以内に「入る」が押せる
7. 新しい作品を `works/` に画像とメッセージを置いて 1 コマンドで追加できる
8. 作家本人が「これは自分の絵の中だ」「包まれた」と感じる（主観評価。最重要）

## 8. 評価のしかた

- 作家本人の主観評価（8 を 1〜5 で記録、作品ごと）
- 第三者 3 人以上に 3 環境のいずれかで試してもらい、`docs/USERS.md` の 5 分インタビュー
- オンラインの検証：作品を見たことがない人に、サムネイルだけで「良さがわかったか」「買いたいか」を 1〜5 で聞き、体験後にもう一度聞く。差を見る
- QR 読み取りから包まれるまでの時間、作品ページの初回表示時間（スマホ、4G）
