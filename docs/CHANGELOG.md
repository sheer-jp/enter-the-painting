- **VR の最低ライン（S-3）を Day 1 午後に**前倒し。検証順を S-1 → S-3 → S-6 → S-2 → S-4 → S-5 → S-8 → S-7 に

## V2（2026-11-02）コミット `f6d69c3` 以降（ローカルのタグ `plan-v2`）

課題を「会場の小さな絵」だけから、「絵の『世界』が伝わらない 3 場面（会場の小さな絵 P1、オンラインの絵 P2、買ったあとの絵 P3）」に広げた。それに合わせて作るもの・要件・技術を見直した。

**課題・ユーザー**
- P2 オンラインの絵、P3 買ったあとの絵を課題に追加。登場人物 E「オンラインで絵を見る人」を追加
- 「オンラインで買う気持ちになれない」理由を 4 つに分け、この試作が埋めるのは「出会いの瞬間」と「作家の話」、大きさの一部、と明記。手触りは埋めない
- 販売ツールにしない、を方針として明記

**作るもの**
- オンラインギャラリーを「やれたらやる」から必須に。会場の QR と対等の入口
- 作品ページ `/w/<id>/` を固定 URL に。共有時に絵とタイトルが出る（OGP）を必須に
- 作家への連絡リンク（1 つ）を必須に。販売状況の表示を推奨に
- 接近を「絵をタップでギュンと近づく（1.2 秒）」に変更。歩く・長押しは副。自動接近は実機で要否判断
- 声は日本語のみ、訳さない。文字が母語で字幕の役割
- 作品数を 1〜3 点から 5 点に

**体験（V2 の途中で決めたこと）**
- VR 以外には没入が無いので、PC・スマホで空間を歩く・見回すのをやめ、「物語モード」（絵が画面いっぱいに拡大 → シュワシュワと溶ける → 流体のアニメーションの奥から文字が浮き、声が物語のように語る → 絵に戻る）にした。流体・文字・声は VR と共通
- 「3 環境で同じ Scene」の原則を「同じ流体・同じメッセージ、VR は空間、他は映像」に変更
- 作品ページに「部屋で見る」を必須で追加。家・ホテル・カフェなど AI 生成の部屋に、実物の絵を実寸で合成（絵は生成モデルに入れない。「部屋は AI、絵は実物」と明記）
- 各部屋に「小さな物語」（その絵のある日々を描いた 3〜5 文、作家の声、Claude が下書き、10 言語）を推奨で追加。生活の中のアート
- 溶ける演出を「シュワシュワ」（縁から内側へ泡が立つようにほどける、3 秒、泡の音）と定義

**要件・技術**
- `docs/REQUIREMENTS.md` を新設。要件に ID を振り、課題・人・場面・優先度・受け入れ条件に紐づけ
- 非機能要件を追加：作品ページは JS を待たず 2 秒で絵が見える、4G で 5 秒以内に「入る」、JS バンドル gzip 300KB 以下、流体テクスチャとフォントは「入る」後に読む
- 計測（入った / 最後まで見た / 連絡先を押した）を推奨に。Cookie なし、個人を特定しない
- 体験（流体・包む・文字）、three.js + 自前 GPU 流体 + troika、10 言語の方針は V1.5 から変更なし

**日程**
- Day 5 に作品ページの初回表示の速さ、OGP、連絡リンクを追加。Day 7 にオンラインの検証（サムネイルだけ → 体験後の比較）を追加
