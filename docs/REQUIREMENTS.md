# 要件定義 V2

各要件は、課題（P1 会場の小さな絵 / P2 オンラインの絵 / P3 買ったあとの絵）、登場人物（A〜E、`docs/USERS.md`）、場面（G、S0〜S5、`docs/EXPERIENCE.md`）に紐づける。
優先度は **必須**（MVP に無いと提出しない）、**推奨**（時間があれば MVP に入れる）、**将来**（今回はやらない）。
