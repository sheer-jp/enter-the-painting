# 設計：絵の大きさを顧客に伝える（部屋で見る）V0

作家の狙い：「F15 の絵が、その部屋に置くと実際どのくらいの大きさか」を顧客が知りたい。小さい部屋では大きく、広い部屋では普通に感じる、その差がそのまま出てよい。
決めたこと：縮尺は家具や建具の実寸（cm）から決める（`docs/SCALE.md`）。寸法線はパッと見では出さず、ホバー（スマホはタップ）で出す。比較の一文は入れる。

## 1. 何を伝えるか（優先順）

1. **その部屋での見え方**：縮尺の正しい合成画像（今ある）。これが主役で、数字より先に目に入る
2. **身近な物との比較**：「このドア（高さ 200 cm）の約 3 分の 1」。数字が苦手な人にも入る
3. **寸法そのもの**：「F15 / 53 × 65.2 cm」。知りたい人だけが、ホバーやタップで見る

数字を常に見せると図面になってしまい、`docs/DESIGN.md` の静けさが崩れる。だから 3 は隠しておき、1 と 2 を見せる。

## 2. 単位と縮尺の定義（確定）

- **実寸は cm**。作品は `size_cm`（幅, 高さ）、基準物は共通の寸法表 `rooms/REFERENCES.json` に cm で持つ
- **画像上は px/cm**。部屋ごとに `px_per_cm = 基準物の px ÷ 基準物の cm`。基準物は壁と同じ平面にある物だけ（ドア、机、棚、カウンター、ナイトテーブル、天井〜床）
- **複数の基準物で交差確認**。主の基準物で px/cm を決め、他の基準物とのずれで信頼度を自動で決める：ずれ 8% 以内 → high、15% 以内 → mid、それ以上 → low。low の部屋は「寸法は目安」を強く出す
- 各部屋の JSON は「どの物を何 px で測ったか」だけを書く。実寸は寸法表から引く（手入力の実寸をなくし、根拠を 1 か所にする）

```jsonc
// rooms/REFERENCES.json（抜粋）
{ "door_interior":  { "height_cm": 200, "width_cm": 78,  "label": { "ja": "室内のドア", "en": "the door" } },
  "door_entrance":  { "height_cm": 205, "width_cm": 85,  "label": { "ja": "玄関のドア", "en": "the front door" } },
  "ceiling":        { "height_cm": 240,                   "label": { "ja": "天井の高さ", "en": "the ceiling" } },
  "desk":           { "height_cm": 72,  "width_cm": 110, "label": { "ja": "机", "en": "the desk" } },
  "nightstand":     { "height_cm": 55,  "width_cm": 45,  "label": { "ja": "ナイトテーブル", "en": "the nightstand" } },
  "low_shelf":      { "height_cm": 42,  "width_cm": 100, "label": { "ja": "低い棚", "en": "the low shelf" } },
  "kitchen_counter":{ "height_cm": 85,                   "label": { "ja": "キッチンのカウンター", "en": "the kitchen counter" } },
  "kettle":         { "height_cm": 24,                   "label": { "ja": "ケトル", "en": "the kettle" } },
  "sofa_2seat":     { "height_cm": 80,  "width_cm": 160, "label": { "ja": "ソファ", "en": "the sofa" } } }

// rooms/living-apartment.json（抜粋）
{ "references": [ { "ref": "door_interior.height", "px": 725, "primary": true },
                  { "ref": "ceiling.height", "px": 845 } ],
  "hang": { "x_px": 800, "floor_y_px": 845, "center_from_floor_cm": 150 } }
```

`generate` が px/cm・信頼度・比較文を計算して `space.json` の `rooms[]` に入れる。作家が触るのは JSON の `references` だけ。

## 3. 比較の一文（自動生成）

- **どの物と比べるか**：部屋にある基準物のうち、顧客に馴染みがある順で 1 つ。ドア > ソファ > 机 > 棚 > カウンター > ナイトテーブル > 天井。写真に写っている物に限る（JSON の `references` にある物 = 写っている物）
- **何と比べるか**：絵の高さを基準物の高さと比べる。幅の方が近い場合（横長の絵とソファなど）は幅
- **言い方**：比率を身近な分数に丸める。0.9〜1.1 → 「ほぼ同じ高さ」、0.6〜0.75 → 「約 3 分の 2」、0.45〜0.55 → 「約半分」、0.28〜0.38 → 「約 3 分の 1」、0.2〜0.28 → 「約 4 分の 1」、それ以外は「約 0.4 倍」のように小数 1 桁。1 を超えるなら「約 1.5 倍」
- **文の形**（ja）：「F15 号（53 × 65.2 cm）。このドア（高さ 200 cm）の約 3 分の 1。」（en）"F15 (53 × 65.2 cm), about one third the height of the door (200 cm)." 他の 8 言語は既存の翻訳パイプラインで（文の型が固定なので、型ごとに 1 回訳せば使い回せる）
- 信頼度 low の部屋は末尾に「（寸法は目安）」を付ける。mid 以上は付けない（キャプションに「寸法は目安」の注記が既にある）
- 例：
  - living-apartment：F15 → 65.2 / 200 = 0.33 → 「このドアの約 3 分の 1」
  - studio-desk：F4（24 × 33）→ 33 / 72 = 0.46 → 「この机の高さの約半分」
  - studio-kitchen：F4 → 33 / 24 = 1.4 → 「このケトルの約 1.4 倍」

## 4. 寸法線（ホバー / タップで出す）

- **画像には焼き込まない**。HTML の上に SVG を重ねる（座標は `space.json` の `quad_px` と `image_px` から）。画像はきれいなまま、線は拡大してもにじまず、文字は母語で出せる
- **出し方**：PC はホバーで 0.3 秒のフェードで出て、外すと消える。スマホはタップで出て、もう一度タップで消える。画像の右下に小さな「寸法」ピル（11px、字間広め）を置いて、ホバーできない端末でも見つけられるようにする。キーボードではピルにフォーカスして Enter
- **描くもの**：絵の下に幅の寸法線、右に高さの寸法線（細い線、両端に短い目盛り、`docs/DESIGN.md` の `--ink` を 80% の不透明度、下に薄い影）。ラベル「53 cm」「65.2 cm」と、絵の左上に「F15」。線は絵から 12 px 離す。ラベルが画像の外に出るなら内側に折り返す
- **出さないもの**：床の線や基準物の線（確認用画像だけにある）。顧客向けには絵の寸法だけ
- **小さな絵**：絵が画像上で 60 px より小さいとき、ラベルは絵の外側にまとめて 1 行で出す（「F4 / 24 × 33 cm」）。重なりを避ける

## 5. 寄りの画像の扱い

今は全景の隣に「寄り」の画像を並べているが、並ぶと帯が長くなり、どちらを見ればよいか迷う。**全景だけを並べ、画像をタップ / クリックすると拡大表示（ライトボックス）**にして、その中で寄りを見られるようにする。寄りの切り出し画像は不要になる（拡大表示は全景画像を CSS で拡大すればよい）。寸法線は拡大表示の中でも同じ座標で出る。

→ 変更：`room_<name>_close.jpg` の生成と `.room-close` の図を外す。

## 6. 体験の終わり（絵が部屋に掛かる）との整合

終わりの演出は全景画像（寸法線なし）をそのまま使う。絵が壁に着地したあと、比較の一文を画面下に 1 行だけ出す（「このドアの約 3 分の 1」）。数字は出さない。ここでも「大きさは部屋の物との比較で伝える」を通す。

## 7. 作品ページの構成（部屋で見る の節）

1. ラベル「ROOMS 部屋で見る」
2. 横スクロールの帯：全景画像（ホバー / タップで寸法線、右下に「寸法」ピル）
3. 各画像のキャプション：**比較の一文**（明朝、15px）＋ 注記（部屋は AI 生成のイメージ。絵は実物の写真。寸法は目安。11px）
4. 帯の下に 1 行：「この作品は F15 号、53 × 65.2 cm。」（小さなゴシック、数字は tabular）

## 8. 受け入れ条件

- 作品を見たことがない第三者 3 人に、寸法線なしの全景だけを見せて絵の幅を言ってもらい、±30% に入る。寸法線と比較文を見せたあとは ±10%
- 作家が 3 部屋以上で「実物の大きさに見える」と言う
- 比較の一文が 10 言語で不自然でない（zh / ko / fr は母語話者 1 人に見てもらう）
