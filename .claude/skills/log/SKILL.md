# /log

`docs/LOG.md` の先頭（見出し「---」の直後）に、今回の作業のエントリを追記する。

## 手順

1. `git log --oneline -10` と `git status` と、この会話での作業内容から、今回やったことを集める
2. 今日の日付の見出しがすでにあれば、そのエントリに追記する。無ければ新しく作る。見出しは `## YYYY-MM-DD（Day N）`。Day N は `docs/SCHEDULE.md` の日程から数える
3. 4 項目で書く。各項目は箇条書き 1〜4 行。無い項目は「なし」と書く
   - **やった**：成果物とコミット。ファイル名を 1 行に 1 つまで
   - **決めた**：設計・方針の決定と理由。あとで覆すときに参照できる粒度で
   - **困った・学んだ**：つまずき、回避策、環境の制約、わかった事実
   - **次にやる**：次回の最初の 1〜3 個。`docs/SCHEDULE.md` と矛盾しないように
4. 実機チェックや第三者テストをしたなら、結果は `docs/USERS.md` の記録欄にも書く
5. 追記したら、追記した内容をそのまま短く返す。コミットはしない（`/close` が行う）

## 書き方

- 日本語。事実と決定だけ。感想は「困った・学んだ」にだけ
- すでに書いてあることは繰り返さない
