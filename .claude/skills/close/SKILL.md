# /close

`docs/ROUTINE.md` の「作業の終わり方」を実行する。順番を守り、途中で落ちたら止まって報告する。

## 手順

1. **差分の確認**：`git status` と `git diff --stat`。変更が無ければ「変更なし」と伝えてログだけ書く
2. **テスト**
   - `package.json` に `test` があれば `npm test`、`smoke` があれば `npm run smoke` を実行する
   - まだ無ければ、`npm run dev` を起動して `http://localhost:5173/?w=sample` を Playwright（headless）で開き、コンソールエラーが 0 であることを確認する。起動できる状態にないときはスキップし、その理由をログに書く
   - 落ちたら直す。直せないなら、理由と再現手順をログに書いて次へ進む
3. **レビュー**：`/code-review` を実行する（効果レベルは medium）。指摘は直す。直さないものは理由をログの「決めた」に書く。ドキュメントだけの変更ならレビューは省略してよい
4. **作業ログ**：`/log` の手順で `docs/LOG.md` に追記する
5. **コミット**：日本語の 1 行メッセージで、関連する変更をまとめて 1 コミット。性質が違う変更が混ざっていれば分ける
6. **push**：`git push origin main`。失敗したら 2 秒・4 秒・8 秒・16 秒の間隔で最大 4 回まで再試行
7. 最後に、テストの結果、レビューの指摘と対応、コミットのハッシュ、次にやることを短く報告する

## 守ること

- テストとレビューを飛ばしてコミットしない。飛ばしたなら必ずログに理由を書く
- `works/*/generated/` は 1 作品あたり合計 20MB を超えたらコミットせず報告する
- `.env` と音声の原本（`*.wav`）はコミットしない
